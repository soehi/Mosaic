# 浮窗工具栏图标

三个按钮沿用从左到右的打开主窗口、置顶和关闭顺序。使用 16×16 DIP 的矢量图标、统一的 1.7 DIP 圆端描边和 28×28 DIP 的点击区。打开主窗口用窗口轮廓和外向箭头，图钉以空心和实心区分状态，关闭用 X。按钮继承主题的悬停、按下与键盘焦点反馈，关闭按钮在悬停和按下时使用危险色。

浮窗 WPF 模块管理图标资源、按钮样式与本地化提示。置顶操作落盘后，窗口与图标从同一条 `FloatingWindowRecord` 读取状态。每个按钮通过模板生成独立的非命中图标元素，原有按钮继续接收短按和超过阈值的拖动。工具栏实测宽度继续传给任务内容以预留标题空间。

验收覆盖两个浮窗、220 DIP 紧凑窗、展开窗、置顶保存失败与重启恢复。实际指针回归从三个新图标中央起拖，并确认短按可用。浅色、深色和高对比度分别检查实际 WPF 渲染。数据与配置格式沿用上一版，使用已有浮窗记录检查恢复。详细验证结果见[实施记录](implementation-status.md)。
