# Mosaic 0.16.3

Mosaic 0.16.3 · 更新日期 2026-11-19
适用范围：0.16.2 → 0.16.3

功能改进
1. 安装包自带配置修复功能：每次启动自动把内置模块的默认能力绑定合并进配置，缺失的绑定（包括模块升级新增的能力）会被补齐并写回 appsettings.json，从旧版本升级后不再因为缺少新增 provider 绑定而启动失败；用户显式修改过的绑定保持不变，MSI 修复/重装后的首次启动同样会自动补齐。包含 0.16.2 的全部内容：修复从 0.15.3 或更早版本升级后无法启动的问题（tasks.transfer-repository@1 绑定缺失）。
