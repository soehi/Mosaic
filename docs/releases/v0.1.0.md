# Mosaic 0.1.0 / 0.2.0

Mosaic 的首个 Windows 桌面版本，面向本机离线使用，采用模块化 WPF 界面与 SQLite 持久化。

## 主要功能

- 创建、查看、编辑和删除任务。
- 按全部、未完成、已完成筛选任务。
- 完成、恢复任务，并处理并发编辑冲突。
- 自动保留未保存编辑，关闭应用或切换任务前进行确认。
- 数据保存在本机，卸载应用不会删除用户数据。
- 支持浅色、深色、高对比度和跟随系统主题，以及宽窄窗口响应式布局。
- 设置项提供中英文界面文案；主题与语言可在保存前即时预览，放弃修改会自动还原。
- 提供设置页，可调整任务规则、界面文案、主题与布局参数，并支持危险项警告和恢复默认。
- 0.2.0 补全设置闭环：57 项参数全部位于任务、外观与布局、存储与系统、文案四个分区，统一在高级门槛后展示；窗口启动尺寸、侧栏断点、存储队列/日志模式等宿主与存储参数真正生效；设置持久化与宿主配置写回具备原子回滚。
- 0.2.0 优化任务页布局：默认窗口 1504×1012，最小窗口 1100×720；宽窗口列表与编辑栏同屏，窄窗口通过紧凑排版、换行和滚动适配，不把编辑栏移到左侧。
- 窗口标题与侧栏状态区显示版本号与提交短哈希，便于区分发布包与本地构建。

## 安装

下载 `Mosaic-0.2.0-win-x64.msi` 并运行（0.1.0 历史安装包保留）。安装程序为每用户安装，支持 Windows 10 2004（build 19041）及以上的 x64 系统，自带 .NET 10 运行时。
