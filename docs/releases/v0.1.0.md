# Mosaic 0.1.0

Mosaic 的首个 Windows 桌面版本，面向本机离线使用，采用模块化 WPF 界面与 SQLite 持久化。

## 主要功能

- 创建、查看、编辑和删除任务。
- 按全部、未完成、已完成筛选任务。
- 完成、恢复任务，并处理并发编辑冲突。
- 自动保留未保存编辑，关闭应用或切换任务前进行确认。
- 数据保存在本机，卸载应用不会删除用户数据。
- 支持浅色、深色和高对比度系统主题，以及宽窄窗口响应式布局。

## 安装

下载 `Mosaic-0.1.0-win-x64.msi` 并运行。安装程序为每用户安装，支持 Windows 10 2004（build 19041）及以上的 x64 系统，自带 .NET 10 运行时。
