# Mosaic 0.17.3

Mosaic 0.17.3 · 更新日期 2026-11-20
适用范围：首次使用 → 0.17.3

新增功能
1. 首次安装可选择安装位置：安装向导提供路径输入、浏览与「恢复默认」，默认目录为 %LOCALAPPDATA%\Programs\Mosaic，桌面与开始菜单快捷方式始终指向最终安装目录。
2. 同一版本已安装后再次运行安装包会自动进入「检查与修复」：先扫描程序文件，全部完好时只提示无需修复，不重装、不关闭正在运行的程序；仅当文件缺失或损坏时才通过 Windows Installer 修复并复检。
3. 安装包内嵌原生扫描器与载荷清单（相对路径、大小、SHA-256、组件映射），不依赖安装目录中的程序或清单，即使可执行文件、运行时 DLL 或整个安装目录被删除仍能发现并恢复缺失文件。
4. 安装后在「应用和功能」登记实际安装位置（ARPINSTALLLOCATION），同时写入 HKCU\Software\Mosaic\Installer，便于维护、升级与卸载定位。

功能改进
1. 升级保持原有安装位置：新版本在已安装场景下原地继承登记位置，不再回到默认目录；0.17.2 及更早未登记位置的安装在确认产品身份后回退到旧固定默认目录。
2. 安装路径校验在追加 Mosaic 子目录后复核：与用户数据目录重叠、指向系统目录、UNC 路径、卷根或含重解析点的路径都会被拒绝，避免程序文件与用户数据混放。
3. 维护扫描只读：健康安装不写入任何文件；只有需要修复时才进入 Windows Installer 事务，用户数据、凭据、配置与备份不受影响。

问题修复与兼容变化
1. 修复维护与修复时丢失安装位置登记：SetArpInstallLocation 原先只在全新安装时设置，现在已确认位置的维护也会写入 ARPINSTALLLOCATION。
2. 修复产品身份冲突时错误原因被通用提示覆盖：启动条件现在显示具体的 [MOSAICSTATEERROR]，可区分「同版本但身份不同」与「已安装更新版本」。
