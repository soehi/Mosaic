# Mosaic 0.16.0 交付文件清单

## 账户模块（新增）

- `src/Modules/Auth/Mosaic.Auth.Contracts/AuthContracts.cs`：`AuthStatus`、`AuthErrorCodes`、`AuthValidation`（邮箱/密码 10–256/6 位验证码/服务器 HTTPS 与 origin 校验）、`AuthAccountDto`、`AuthPolicyDto`、`DeviceAuthorizationDto`、`AuthState`、`AuthSecrets`，以及 `IAuthApi`、`IAuthTransport`、`IAuthSecretStore` 契约。
- `src/Modules/Auth/Mosaic.Auth.Core/AuthModule.cs`：模块 `auth-core`（提供 `auth.api@1`，依赖 `auth.transport@1`、`auth.secrets@1`、`settings.api@1`），`AuthDependencies` 装配 `AuthService` 与 `AuthSettingsSource`。
- `src/Modules/Auth/Mosaic.Auth.Core/Internal/AuthService.cs`：登录状态机；注册/密码登录/验证码登录/找回与重置密码；设备授权启动、轮询、取消与过期；刷新令牌持久化与退出撤销；离线启动只读本地凭据、不发起网络请求。
- `src/Modules/Auth/Mosaic.Auth.Core/Internal/AuthSettingsSource.cs`：设置项 `auth.serverUrl`（模块 `auth-core`），服务器地址变更时通知 `AuthService`。
- `src/Modules/Auth/Mosaic.Auth.Core/Internal/GuardedAuthApi.cs`：经 `IModuleExecutionGate` 与 `IDiagnosticSink` 包装的公开 API。
- `src/Modules/Auth/Mosaic.Auth.Http/HttpAuthTransport.cs`：`/v1` 账户端点、JSON 线格式、错误码映射、强制 HTTPS（回环开发例外）。
- `src/Modules/Auth/Mosaic.Auth.Http/HttpAuthModule.cs`：模块 `auth-http`（`auth.transport@1`），唯一持有 `HttpClient` 的账户传输实现。
- `src/Modules/Auth/Mosaic.Auth.Windows/WindowsAuthSecretStore.cs`：DPAPI（entropy `Mosaic.Auth.Secrets.v1`）加密的 `credentials.dat`，原子写入；损坏或异账户文件按未登录处理；拒绝 http 服务器与空令牌。
- `src/Modules/Auth/Mosaic.Auth.Windows/AuthWindowsModule.cs`：模块 `auth-windows`（`auth.secrets@1`）。
- `src/Modules/Auth/Mosaic.Auth.Wpf/AuthUiModule.cs`、`Internal/AuthViewFactory.cs`、`Internal/AuthLocalization.cs`：模块 `auth-ui`，注册左侧导航「账户」页与视图工厂、错误码本地化。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AccountViewModel.cs`：账户页全部交互——登录/注册/忘记密码、设备授权码（`BAAD-C832` 格式）、服务器地址编辑、离线使用、备份上传/下载确认、同步开关持久化、退出登录确认。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Views/AccountView.xaml`、`AccountView.xaml.cs`：账户页界面，沿用现有主题与高 DPI 布局。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Localization/en.xaml`、`zh.xaml`：账户页中英文文案。
- 各项目 `Mosaic.Auth.*.csproj` 与 `packages.lock.json`。

## 备份同步模块（新增）

- `src/Modules/Sync/Mosaic.Sync.Contracts/SyncContracts.cs`：`SyncItemKinds`、`SyncErrorCodes`、`BackupItemDto`、`BackupSnapshotDto`、`BackupSnapshotContentDto`、`BackupUploadResult`、`RestoreSummary`、`SyncState`，以及 `ISyncApi`、`ISyncTransport`。
- `src/Modules/Sync/Mosaic.Sync.Core/SyncModule.cs`：模块 `sync-core`（提供 `sync.api@1`，依赖 `auth.api@1`、`sync.transport@1`、`tasks.transfer@1`、`settings.api@1`）；未登录或关闭同步时直接返回 `SYNC_DISABLED` / `SYNC_NOT_SIGNED_IN`。
- `src/Modules/Sync/Mosaic.Sync.Core/Internal/SyncService.cs`：导出经 `ITaskTransferApi` 取归档全量；设置只取白名单（`appearance.theme`、`ui.language`、`tasks.` 与 `ui.text.` 前缀）；上传前校验快照 SHA-256；下载后单事务替换任务再应用可移植设置。
- `src/Modules/Sync/Mosaic.Sync.Core/Internal/SyncSettingsSource.cs`：设置项 `sync.enabled`、`sync.includeSettings`。
- `src/Modules/Sync/Mosaic.Sync.Core/Internal/GuardedSyncApi.cs`：经执行门与诊断包装的公开 API。
- `src/Modules/Sync/Mosaic.Sync.Http/HttpSyncTransport.cs`：`/v1/backups` 上传、latest 元数据与按 ID 下载，错误码映射与 HTTPS 强制。
- `src/Modules/Sync/Mosaic.Sync.Http/HttpSyncModule.cs`：模块 `sync-http`（`sync.transport@1`）。
- 各项目 `Mosaic.Sync.*.csproj` 与 `packages.lock.json`。

## 任务全量导出与替换

- `src/Modules/Tasks/Mosaic.Tasks.Contracts/TaskTransferContracts.cs`：`ITaskTransferApi.ExportAllAsync` / `ReplaceAllAsync`。
- `src/Modules/Tasks/Mosaic.Tasks.Persistence.Contracts/ITaskTransferRepository.cs`：持久层整表替换契约。
- `src/Modules/Tasks/Mosaic.Tasks.Core/Internal/TaskTransferService.cs`：导出使用 `ArchiveScope = All`；替换前逐行校验（Id 非空且不重复、Revision ≥ 1、时间戳顺序、标题长度）并限制 100 000 行；成功后经 `TaskChangeSource` 发布变更。
- `src/Modules/Tasks/Mosaic.Tasks.Core/Internal/GuardedTaskTransferApi.cs`：执行门、诊断与错误包装。
- `src/Modules/Tasks/Mosaic.Tasks.Core/TasksModule.cs`：新增能力 `tasks.transfer@1`，`TasksDependencies.TransferRepository` 注入后暴露 `Transfer`；未注入时为 `null`，既有宿主行为不变。
- `src/Modules/Storage/Mosaic.Tasks.Sqlite/Internal/SqliteTaskTransferRepository.cs`：单事务删除并重插，保留原 Id/Revision/时间戳。
- `src/Modules/Storage/Mosaic.Tasks.Sqlite/TasksSqliteModule.cs`：新增能力 `tasks.transfer-repository@1` 并暴露 `TransferRepository`。
- `src/Modules/Storage/Mosaic.Tasks.Sqlite/Internal/SqliteTaskRepository.cs`：`Values(TaskItemDto)` 改为 `internal static` 供替换仓库复用映射。

## 桌面宿主装配与迁移

- `src/Mosaic.Desktop/BuiltInModuleCatalog.cs`：装配 `auth-http` → `auth-windows` → `auth-core` → `sync-http` → `sync-core` → `auth-ui`，并把 `tasks.transfer-repository@1` 注入 `TasksDependencies`；账户模块先于备份模块装配，缺失依赖时抛出明确异常。
- `src/Mosaic.Desktop/AppConfiguration.cs`：新增迁移 `auth-sync-v1`（登记模块、`auth.transport@1` 等五项 provider、三项设置），`AuthSecrets => <Root>/Auth/credentials.dat`。
- `src/Mosaic.Desktop/appsettings.json`：默认模块列表与 provider 表补入账户/同步模块，`appliedMigrations` 含 `auth-sync-v1`。
- `src/Mosaic.Desktop/Mosaic.Desktop.csproj`、`packages.lock.json`：引用八个新项目。
- `src/Modules/Settings/Mosaic.Settings.Wpf/Localization/en.xaml`、`zh.xaml`：新增三个设置项的标题与说明。
- `Mosaic.sln`：登记 8 个产品项目与 3 个测试项目。

## 构建契约

- `build/project-boundaries.json`：新增账户/同步各项目的允许依赖，限定 `HttpClient` 只在 `Mosaic.Auth.Http`、`Mosaic.Sync.Http`，DPAPI 只在 `Mosaic.Auth.Windows`。
- `build/public-api.txt`：登记 `Mosaic.Auth.Contracts`、`Mosaic.Sync.Contracts`、`Mosaic.Tasks.Contracts`（`ITaskTransferApi`）、`Mosaic.Tasks.Persistence.Contracts` 的公开 API。
- `tests/Mosaic.Architecture.Tests/BoundaryTests.cs`：`IsWindowsProject` 统一判定 Windows 目标框架（含 `Mosaic.Auth.Windows`、`Mosaic.Auth.Wpf`），模块→程序集表补充 `auth-core`、`sync-core`。
