# Mosaic 0.15.0 交付文件清单

## 已归档任务导航（需求一）

- `src/Modules/Tasks/Mosaic.Tasks.Wpf/TasksUiModule.cs`：`Navigation` 增加第二项 `tasks.archived.navigation`（标签键 `Tasks.Archived.Navigation`，图标键 `folder`，视图 `tasks.archived.list`，Order 110）；`Views` 增加 `tasks.archived.list` 贡献，使用 `TaskViewFactory(dependencies, _settingsTarget, 3)`。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TaskViewFactory.cs`：构造函数增加可选 `int? initialFilter`；`Create()` 在构造 `TasksViewModel` 后设置 `FilterIndex`，使归档页初始筛选为“已归档”且不写入用户默认筛选设置。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TasksViewModel.cs`：新增 `ListTitle`（`FilterIndex == 3` 时为 `Tasks.ListTitle.Archived`，否则 `Tasks.ListTitle`）；`SetFilter` 与 `RefreshLocalizedText` 同步通知，切换筛选和语言时标题一致刷新。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Views/TasksView.xaml`：列表标题由 `DynamicResource Tasks.ListTitle` 改为 `Binding ListTitle`，归档页显示“已归档任务”。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Localization/zh.xaml`、`en.xaml`：新增 `Tasks.Archived.Navigation`、`Tasks.ListTitle.Archived`。

## 未完成不自动归档（需求二）

- `src/Modules/Settings/Mosaic.Settings.Wpf/Localization/zh.xaml`、`en.xaml`：`Settings.Setting.AutoArchive.Description` 明确“仅自动归档已完成且等待期已满、未恢复的任务；未完成任务永远不会被自动归档；关闭时不自动归档任何任务”。
- `src/Modules/Tasks/Mosaic.Tasks.Core/Internal/TaskSettingsSource.cs`：设置定义内联描述同步为同一文案（与本地化键一致）。
