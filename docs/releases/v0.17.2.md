# Mosaic 0.17.2

Mosaic 0.17.2 · 更新日期 2026-11-20
适用范围：首次使用 → 0.17.2

功能改进
1. 设置容器与模块页面职责分离：分区标题只由设置容器显示，模块页面获得完整可用宽高并自己处理滚动与内边距；维护页卡片跟随窗口宽度填满，不再贴边或固定在 820 DIP 宽度。
2. 维护页重排为「存储位置」「应用维护」两张卡片：修复与卸载分成两组，删除数据复选框文字可换行，路径选择按钮在窄窗口下移到输入框下一行，操作按钮与说明可换行。
3. 进入维护等模块操作页时隐藏「0 项设置」、通用参数说明、高级设置开关与恢复默认；切回参数页恢复显示，参数页的预览、保存与恢复规则不变。

问题修复与兼容变化
1. 修复维护页连续显示两个「维护」标题：容器与页面各写一份分区标题，删去页面标题后只保留容器标题。
2. 通用设置不再显示「账号服务器地址」：该设置标记为仅供模块使用，普通与高级模式都不展示，也不进入条目计数与恢复默认；账户流程仍读取并保存该地址，已有地址与登录凭据保持不变。
