# Mosaic 0.16.2

Mosaic 0.16.2 · 更新日期 2026-11-19
适用范围：首次使用 → 0.16.2

问题修复与兼容变化
1. 修复从 0.15.3 或更早版本升级后无法启动的问题：启动时弹出「模块依赖或能力绑定无效：Provider binding is missing or incompatible: tasks.transfer-repository@1」。原因是 0.16.0 的配置迁移没有为任务传输流水线的两个新能力（tasks.transfer-repository@1 与 tasks.transfer@1）写入 provider 绑定，本次升级会自动补全绑定，无需手动修改配置文件；0.16.0/0.16.1 全新安装不受影响。
