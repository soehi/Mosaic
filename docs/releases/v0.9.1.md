# Mosaic 0.9.1

Mosaic 0.9.1 · 更新日期 2026-11-17
适用范围：首次使用 → 0.9.1

新增功能
1. Windows 安装完成后自动在当前用户桌面创建 Mosaic 快捷方式；同位置升级和修复后目标指向最终安装目录。

问题修复与兼容变化
1. 桌面和开始菜单快捷方式由 MSI 同一组件生命周期管理；卸载移除本产品创建的入口，任务数据和设置保持不变。
2. 修复应用级 Dispatcher 与 Shell 窗口不在同一线程时，设置预览可能等待已停止 Dispatcher 而超时的问题；设置页优先使用当前窗口的 Dispatcher。
