# Mosaic 0.16.0

Mosaic 0.16.0 · 更新日期 2026-11-19
适用范围：首次使用 → 0.16.0

新增功能
1. 左侧导航新增“账户”页。登录完全可选：不连接任何服务器也能使用全部本地功能，启动时不联网、不强制登录。
2. 账户页提供四种进入方式：在浏览器中登录（设备授权码，如 BAAD-C832，自动轮询直到完成）、连接其他自建服务器、不连接服务器离线使用、忘记密码（邮箱验证码重置）。
3. 支持邮箱注册：6 位数字验证码、密码（10–256 个字符）与确认密码，注册成功后自动登录。
4. 登录后可把任务与可移植用户设置备份到自建服务器，并在其他设备上恢复。第一阶段为显式上传 / 下载，下载会覆盖本机任务，操作前必须确认。

功能改进
1. 刷新令牌与设备身份只用 Windows DPAPI 加密保存在本机 Auth/credentials.dat，文件非明文；其他 Windows 账户或机器上的副本无法使用，损坏的文件按“未登录”处理。
2. 备份只包含任务与可移植设置（外观主题、语言、任务相关设置与界面文案）；不同步服务器地址、模块装配、机器路径、驻留/自启、令牌、同步开关或日志。
3. 恢复任务时保留原任务 ID、修订号与创建/完成/归档时间戳，并在单个事务内整体替换；恢复设置只应用白名单内的可移植项。
4. 所有网络请求强制 HTTPS（仅开发测试用回环地址例外），服务器地址只保存归一化后的 origin；更换服务器会清除旧凭据。
