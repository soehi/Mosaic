# Mosaic 0.16.1

Mosaic 0.16.1 · 更新日期 2026-11-19
适用范围：首次使用 → 0.16.1

新增功能
1. 账户页新增「已登录会话」管理：查看全部会话（设备、平台、最近活跃时间、当前设备标记），可撤销单个会话或一键登出其他设备。
2. 账户页新增「删除账号」入口：密码或邮箱验证码双重校验、删除前二次确认，删除成功后本机凭据即被清除。
3. 设备授权启动请求上报 platform=windows 与 appVersion；备份上传/下载响应新增 serverRevision 与 cursor 字段，为后续增量同步预留。

功能改进
1. 备份的设置白名单收紧为与服务端一致的 14 个精确键，tasks.revisionStart、任务速览编辑开关等宿主/机器相关设置不再进入备份；此前这些键会触发服务端拒绝整个备份（400 sync.invalid / backup.invalid）。
2. 设备授权轮询按服务端 slow_down 提示逐步拉大间隔（从基础间隔起累加、上限 30 秒），不再把 200 slow_down 当作普通等待或错误。
3. 浏览器授权优先打开服务端下发的含码完整链接，服务端未提供时才自行构造 /device?user_code= 链接，不再打开需要手输授权码的裸链接。
4. 新增 auth.reauth_required 与 auth.session_revoked 两个错误码的明确提示；错误响应中的 details 等未知字段被安全忽略，旧客户端不会崩溃。
