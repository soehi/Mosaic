# Mosaic 0.8.0

Mosaic 0.8.0 · 更新日期 2026-11-17
适用范围：首次使用 → 0.8.0

新增功能
1. 可从速览拖出任务，或通过任务按钮上下文菜单在独立小窗中打开；支持多个不同任务，同一任务只保留一个小窗。
2. 悬浮任务窗默认紧凑并置顶，可展开只读备注和时间、复制内容、切换完成状态、移动与调整大小；置顶可按窗取消。
3. 正常退出后恢复尚未单独关闭小窗的位置、模式、紧凑宽度、展开宽高及置顶选择；关闭小窗只关闭展示，不删除任务。
4. 新增“悬浮任务窗”设置分组，包含自动恢复与默认置顶普通项，以及尺寸、数量上限和保存延迟等高级项。

功能改进
1. 任务提交后通过公开变更通知刷新主任务页、速览与独立小窗；窗口模块不读取任务表或任务DTO。
2. 拖动超过系统阈值才启动，内放、Esc、捕获丢失均取消，不向其他应用发送拖放；拖动期间保持速览交互有效。
3. 窗口状态由独立存储模块原子保存，窗口开启去重、状态变更及退出排空通过串行协调器处理。
4. 最小尺寸的可逆设置预览不覆盖已保存窗口偏好；显示器缺失时回退主屏并夹取可用工作区。

问题修复与兼容变化
1. 关闭状态保存失败会保留窗口并提供反馈；退出布局保存失败提供重试、取消或明确的不保存布局退出选择。
2. 确认任务删除时清理恢复资格；暂时读取失败保留恢复记录，超出数量上限的记录同样保留。
3. 旧工作空间通过floating-windows-v1一次性迁移接入新能力，生效层模块和provider同批写入并备份；主动停用后不会重新加回。窗口表使用独立迁移流，保留既有任务数据。
4. 本轮验证不代替全部实机多屏与100–200% DPI矩阵、干净Windows安装升级及系统会话验收。
