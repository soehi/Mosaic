# Mosaic 0.17.0

Mosaic 0.17.0 · 更新日期 2026-11-20
适用范围：首次使用 → 0.17.0

新增功能
1. 设置新增「维护」页：应用内卸载本软件（可选同时删除用户数据，经两次确认，退出后由助手进程执行 msiexec /x，等待父进程结束）、修复安装（msiexec /famus），便携/开发构建自动隐藏不可用的安装操作
2. 存储位置迁移：维护页选择目标文件夹后重启即迁移数据库（含 WAL 检查点与完整性校验），默认保留旧库可选删除，目标目录已有库时拒绝，迁移结果重启后展示

功能改进
1. 移除公开可编辑的存储路径文本设置，数据库位置改由维护页通过校验后的迁移流程写入，避免直接改路径导致新位置出现空库、旧数据被留下
