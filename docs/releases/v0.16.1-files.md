# Mosaic 0.16.1 交付文件清单

本次交付对齐服务端 0.1.1 冻结 wire：收紧备份设置白名单（根因修复）、补齐账户管理端点与 UI、修正 Device Flow 的 `verificationUriComplete`/`slow_down` 语义、映射新增错误码。不改 `server/`、`mobile/`。

## 根因位置

- `src/Modules/Sync/Mosaic.Sync.Core/Internal/SyncService.cs`：原 `PortablePrefixes = ["tasks.", "ui.text."]`（原 16-17 行）与 `IsPortable` 的前缀匹配（原 200-202 行）导致 `tasks.revisionStart`、`tasks.floating.allowNotesEditing`、`ui.text.*` 等宿主/机器相关设置进入备份；服务端 0.1.1 对 setting 条目强制 14 键白名单，未知键返回 400 `sync.invalid` / `backup.invalid`。修复为精确 14 键集合 `PortableIds`。

## 契约

- `src/Modules/Auth/Mosaic.Auth.Contracts/AuthContracts.cs`：
  - `DevicePollDto`：新增 `SlowDownIntervalSeconds`（slow_down 提示间隔）。
  - 新增 `AuthSessionInfoDto`（`Id`、`DeviceLabel`、`Platform`、`CreatedAtUtc`、`LastSeenAtUtc`、`ExpiresAtUtc`、`Current`）。
  - `AuthErrorCodes`：新增 `ReauthRequired`（`auth.reauth_required`）、`SessionRevoked`（`auth.session_revoked`）。
  - `AuthEmailCodePurpose`：新增 `DeleteAccount`。
  - `IAuthTransport`：`StartDeviceAuthorizationAsync` 增加 `appVersion` 参数；新增 `ListSessionsAsync`、`RevokeSessionAsync`、`RevokeAllSessionsAsync`、`DeleteAccountAsync`。
  - `IAuthApi`：`PollDeviceAuthorizationAsync` 返回 `OperationResult<DevicePollDto>`；新增 `ListSessionsAsync`、`RevokeSessionAsync`、`RevokeAllSessionsAsync`、`DeleteAccountAsync`。
- `src/Modules/Sync/Mosaic.Sync.Contracts/SyncContracts.cs`：`BackupSnapshotDto`、`BackupUploadResult` 新增 `ServerRevision`（long）与 `Cursor`（string?）。
- `build/public-api.txt`：登记 `AuthSessionInfoDto`。

## 账户传输（Mosaic.Auth.Http）

- `src/Modules/Auth/Mosaic.Auth.Http/HttpAuthTransport.cs`：
  - `StartDeviceAuthorizationAsync`（`Mosaic.Auth.Http.Internal.HttpAuthTransport`）：请求体补 `platform=windows` 与 `appVersion`；`verificationUriComplete` 优先，缺失时以服务器基址构造 `device?user_code=...`，不返回裸 `verificationUri`。
  - `PollDeviceAuthorizationAsync`：识别 200 `status=slow_down`，返回 `Pending` 并携带 `SlowDownIntervalSeconds`（≥2）。
  - 新增 `ListSessionsAsync`（兼容根数组与 `{sessions:[...]}` 两种形状）、`RevokeSessionAsync`（`POST v1/auth/sessions/{id}/revoke`）、`RevokeAllSessionsAsync`（`POST v1/auth/sessions/revoke-all`，`keepCurrent=true` 时带请求体）、`DeleteAccountAsync`（`POST v1/auth/account/delete`，body `{password, code}`）。
  - `MapCode` / `FallbackMessage`：新增 `auth.reauth_required`、`auth.session_revoked` 映射与默认文案。

## 备份传输（Mosaic.Sync.Http）

- `src/Modules/Sync/Mosaic.Sync.Http/HttpSyncTransport.cs`：`TryReadSnapshot` 解析 `serverRevision` 与 `cursor`。

## 账户服务（Mosaic.Auth.Core）

- `src/Modules/Auth/Mosaic.Auth.Core/Internal/AuthService.cs`：
  - 新增 `AppVersion`：取 `AssemblyInformationalVersion` 并去掉 `+` 后缀，供设备授权启动上报。
  - `PollDeviceAuthorizationAsync`：返回 `DevicePollDto`，slow_down 时向上透传提示间隔。
  - 新增 `ListSessionsAsync`、`RevokeSessionAsync`、`RevokeAllSessionsAsync`、`DeleteAccountAsync`；`DeleteAccountAsync` 校验密码/验证码二选一，成功后清空 DPAPI 凭据并回到 `SignedOut`。
- `src/Modules/Auth/Mosaic.Auth.Core/Internal/GuardedAuthApi.cs`：转发四个新成员与新的 Poll 返回类型。

## 备份服务（Mosaic.Sync.Core）

- `src/Modules/Sync/Mosaic.Sync.Core/Internal/SyncService.cs`：
  - 根因修复：删除 `PortablePrefixes` 前缀匹配，`IsPortable` 改为 `SettingPersistence.UserSettings && PortableIds.Contains(definition.Id)`；`PortableIds` 为与服务端一致的 14 个精确键（`ui.language`、`appearance.theme`、`tasks.sortOrder`、`tasks.defaultFilter`、`tasks.archive.autoEnabled`、`tasks.archive.delayDays`、`tasks.title.maxCharacters`、`tasks.notes.maxCharacters`、`tasks.title.required`、`tasks.defaultCompleted`、`tasks.confirmDelete`、`tasks.confirmUnsaved`、`tasks.showCharacterCount`、`tasks.autoSwitchToAllOnHidden`）。未知键上传前静默忽略；`PrepareRestoreAsync` 恢复侧同样只应用白名单键。
  - `UploadAsync` / 下载路径透传 `ServerRevision` 与 `Cursor`。

## 账户页 UI（Mosaic.Auth.Wpf）

- `src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AccountViewModel.cs`：
  - 新增 `Sessions` 集合与 `RefreshSessionsCommand`、`RevokeSessionCommand`、`RevokeAllSessionsCommand`、`ShowDeleteDialogCommand`、`CancelDeleteCommand`、`SendDeleteCodeCommand`、`ConfirmDeleteCommand`。
  - `PollDeviceAsync`：以绝对时间点调度轮询，slow_down 时按服务端提示累加间隔（Clamp 至 [基础, 30] 秒）。
  - 删除账号：密码/验证码双模式、验证码冷却、`_dialogs.ConfirmAsync` 二次确认；成功后关闭对话框并提示。
  - `InitializeAsync`：已登录时自动拉取会话列表。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AccountConverters.cs`（新增）：`LocalDateTimeConverter`（UTC→本地时间显示）、`CurrentSessionTagConverter`（当前会话标记）。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AuthLocalization.cs`：`ReauthRequired`、`SessionRevoked` 错误码本地化映射。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Views/AccountView.xaml`：新增「已登录会话」卡（列表、撤销单会话、登出其他设备）与「删除账号」卡（双模式对话框、二次确认），注册两个转换器资源。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Localization/en.xaml`、`zh.xaml`：`Auth.Sessions.*`、`Auth.Delete.*` 与两条错误文案的中英文资源。

## 测试

- `tests/Mosaic.Auth.Core.Tests/AuthServiceTests.cs`：Poll 断言改为比较 `DevicePollDto.Status`；现有用例随新返回类型更新。
- `tests/Mosaic.Auth.Core.Tests/Fakes.cs`：`FakeTransport` 新增 `LastAppVersion`、会话/撤销/删除账号记录与结果。
- `tests/Mosaic.Auth.Http.Tests/HttpAuthTransportTests.cs`：新增 12 个用例——`verificationUriComplete` 优先、无则构造 `/device?user_code=`、slow_down 返回 `Pending`+间隔 2、会话列表两种 JSON 形状、撤销单会话/全部会话（带与不带 body）、删除账号密码/验证码请求体、`auth.reauth_required` / `auth.session_revoked` 映射、未知 `details` 字段忽略、删除验证码 purpose 线格式为 `delete-account`。
- `tests/Mosaic.Sync.Core.Tests/SyncServiceTests.cs`：白名单用例更新为精确键匹配（`ui.text.placeholder` 不再上传）；新增「`tasks.revisionStart`、`tasks.floating.allowNotesEditing` 等旧前缀命中键不上传」与「14 个白名单键全定义时精确上传 14 键」两个证明用例。
- `tests/Mosaic.Sync.Core.Tests/Fakes.cs`：`FakeAuthApi` 的 Poll 改返回 `DevicePollDto`，补四个新接口成员。
- `tests/Mosaic.Wpf.Tests/AccountViewModelTests.cs`：`FakeAuth` 补会话/删除账号记录；新增 5 个用例——打开页面加载会话列表、撤销会话从列表移除、删除账号必须二次确认（拒绝时不调用删除）、验证码模式校验 6 位格式、发送删除验证码使用 `delete-account` purpose。
