# Mosaic 0.16.5

Mosaic 0.16.5 · 更新日期 2026-11-19
适用范围：首次使用 → 0.16.5

新增功能
1. 登录/账号选择流程重构为四选一页面：在浏览器中登录（Device Flow，默认官方服务器）、登录已有账号（邮箱+密码）、离线使用、连接自建服务器；首次打开应用或退出登录后都会进入该页面重新选择，忘记密码入口保留。
2. 窗口左下角新增账号卡片，与「本机工作空间」状态区整合显示登录账号（或未登录·离线），已登录时提供「退出登录」按钮：确认后撤销服务器会话、保留本机任务并立即回到账号选择页。

功能改进
1. 左侧导航栏移除「账户」入口，账号管理统一收敛到左下角账号卡片与右下角状态栏，深色两栏首启欢迎页移除，界面与既有浅色导航风格一致。
