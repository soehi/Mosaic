# Mosaic 手机端 0.2.0

> **已作废（2026-11-26）**：这份文档描述的手机端（App UI / 0.2.x 投影）已按 `docs/mobile-refactor-plan.md` 全量删除并重建为无界面客户端，内容仅作历史追溯，不再代表当前实现。


Mosaic 手机端 0.2.0 · 更新日期 2026-11-26
适用范围：首次安装 → 0.2.0（versionCode 3）
平台：Android；桌面端不随本版本发布

本版本是一次完整的安全与数据架构重构：手机端改为只读投影客户端，本地数据库按账号隔离并迁移到新结构，认证与账号切换补齐身份核验。

功能改进
1. 本地数据按 `服务器 + 用户` 双重隔离，每个账号一个独立投影文件；账号 A 的数据在账号 B 登录后不可见、不可残留。
2. 投影数据库升级为 v2 结构：任务行、游标、失败原因全部强类型存储；旧 `mosaic-mobile.db` 整组文件（`.db`/`-wal`/`-shm`）自动归档迁移，不继承旧任务、游标与设置。
3. 同步引擎切换为服务端修订号（server revision）唯一排序：`(kind,key)` 后写胜出、同修订删除胜出、同修订不同任务判定为冲突；每次同步按 200 条一页、单次最多 20 页有界下载。
4. 快照引导：新投影从服务端最新已上传备份重建基线，再从该备份的 cursor 继续拉取仍保留的增量变更；不保证覆盖从未上传快照的任务，中途失败不产生半份本地数据。
5. 设置页重做：移除高对比开关与“重建本地库”按钮，只保留服务器/账号、主题、语言、同步状态、缓存任务数与立即同步。

安全修复
1. 打开本地投影前必须通过 `GET /v1/auth/me` 核验身份；离线时回退到加密存储的会话身份，服务端明确拒绝（401/身份不符）则关闭缓存并清除令牌。
2. 令牌刷新响应如果返回了另一个用户 id，判定为重放/混号，立即作废会话并只读化本地缓存，不再持久化错误账号的令牌。
3. 账号切换、登出与删号路径统一为先发布 `LocalDataCleared`、后发布 `StateChanged`：旧账号投影一定先清空再关闭，不会残留到新账号下。
4. 移除 `PortableSettings`、可写 outbox 与旧的客户端写回同步路线；手机端对服务端完全只读。

迁移与已有安装影响
- 安装 0.2.0 后首次启动：旧 `mosaic-mobile.db` 连同 `-wal`/`-shm` 被整体改名为归档文件保留，新结构从空投影开始；登录后快照引导从服务端最新已上传备份重建，再从备份 cursor 继续拉取仍保留的增量变更。不保证覆盖从未上传快照的任务；本地未上传的旧 outbox 内容按设计废弃。
- 身份不符或迁移失败时，旧文件进入 `projections/quarantine` 隔离目录，应用以未登录/空投影状态继续运行，不会误删原始数据。
- 版本号 0.1.1 → 0.2.0，Android `versionCode` 2 → 3，可直接覆盖安装升级。
