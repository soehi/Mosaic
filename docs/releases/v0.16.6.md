# Mosaic 0.16.6

Mosaic 0.16.6 · 更新日期 2026-11-20
适用范围：首次使用 → 0.16.6

新增功能
1. 账号管理统一移入「设置 → 账户与备份」：开始页提供四个入口——在浏览器中登录（默认官方服务器）、连接其他自建服务器、不连接服务器离线使用、忘记密码；注册、验证码与密码重置全部在浏览器完成，桌面端不再有这些表单。
2. 账户设置只保留一个统一退出图标：在线时确认后撤销服务器会话、清理本机凭据并保留本地任务，离线时不发送任何网络请求，两种情况都返回开始页。
3. 首次选择完成并保存后，之后的启动直接进入主界面；普通退出不再清除首次选择标记，可随时在设置里重新打开开始页。

功能改进
1. 新增设置页扩展点与通用能力解析，模块按绑定向设置贡献页面，Shell 不再为账户页做特殊判断；已归档等现有导航保持不变。
2. 启动时按数据目录与配置是否已存在区分新旧安装，旧安装保留既有选择状态、新安装进入首次选择；分类与选择标记在同一事务内写入，失败回滚并可重试。

问题修复与兼容变化
1. 修复浏览器登录授权后客户端不结束等待的问题：设备码轮询的起始标记错误，导致批准结果永远不会被读取。
2. 修复全新安装被误判为旧安装的问题：单实例初始化会提前创建默认配置，改为在进程启动时先记录配置存在性。
