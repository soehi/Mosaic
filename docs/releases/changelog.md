# 版本变更记录

本文件保留历史版本的逐条变更；安装与功能说明请回到 [根 README](../../README.md)。

0.18.13（2026-11-24）：文档校准发布，产品行为与 0.18.12 一致。新增 `docs/plugins/` 插件文档体系（插件制作教程、插件规范、边界声明、框架规范、UI 规范）与版本变更记录；教程改写为分步体例，四份契约按源码逐条校准（190 处 `文件:行号` 引用），修正「迁移新启用模块的 provider 绑定交给 `RepairProviderBindings` 自动补齐」的错误方向（绑定必须随迁移用 `Dictionary.TryAdd` 写入，否则迁移后的完整校验会以「模块依赖或能力绑定无效」失败且每次启动重复）、设置归属表与根 README 的三处过宽描述。包含 0.18.12 的全部内容。

0.18.12（2026-11-24）：任务速览在刷新或切换筛选时复用已有行与容器，键盘焦点回到原按钮；筛选项的选中状态由程序同步时不再被当成一次用户点击，同一次切换只查询一次；关闭速览后迟到的完成回调或列表结果不再访问已释放的界面元素；账户与备份页的会话行不再硬编码中文，缺失的设备名、平台名与「最近活跃」时间随界面语言切换。包含 0.18.11 的全部内容。

0.18.11（2026-11-24）：速览的最近筛选改由设置库保存为隐藏本机偏好，与「速览默认筛选」分开管理，已有安装的 `Config/task-peek-filter.txt` 在启动时按迁移 ID 幂等导入一次；设置提交改为可等待，驻留模块只在影响弹窗结构或窗口位置的设置变化时刷新，刷新失败写入诊断日志；「账户与备份」「维护」等模块贡献页不再显示通用「高级设置」栏；18 项驻留设置的文案改由单一权威表生成；新增可选接口 `ICompanionFilterSelection` 供宿主订阅筛选变化。包含 0.18.10 的全部内容。

0.18.10（2026-11-24）：任务速览记住上次选择的筛选；账户与备份页补齐空状态、刷新时保留已有会话行并统一按钮样式；任务列表与速览改用圆角状态徽标和矢量回形针显示完成状态与附件。

0.18.9（2026-11-23）：切换到「账户与备份」或「维护」时，保留顶部说明与高级设置栏，左侧导航和右侧内容保持原位。

0.18.8（2026-11-23）：修复任务速览拖出成功后未收起、无法继续拖出其他任务的问题。自动收起遵循现有设置。

0.18.7（2026-11-23）：评审问题收口——启动页改由导航声明默认页，删除首次启动的账户选择设置与跨模块事件链，工作区加载失败显示错误态而不是空白；账户页恢复已登录内容（账户、同步、会话）并去掉重复登出按钮，登出/删除后清空会话与备份/恢复摘要，设备码倒计时改用单调时钟，同步开关提交串行化，未配置服务器不再静默登录官方实例；任务列表读屏改读完整无障碍标签并按数量播报附件；主题词典移除内嵌浅色副本，补齐可编辑下拉框、进度条轨道、禁用态与右键菜单模板；窗口标题栏 chrome 迁入 Shell 层并用虚拟屏幕钳制多显示器位置；修复配置写回把 `storage` 键写成 PascalCase、默认配置缺少 `tasks.attachments@1` 绑定导致每次启动重写配置；升级时自动删除已废弃的 `auth.accountChoiceMade` 设置行。包含 0.18.6 的全部内容。

0.18.5（2026-11-23）：修复 0.18.4 升级后无法启动——迁移摘要原先对嵌入 SQL 的换行敏感，Git 检出或编辑器把 CRLF 与 LF 互换后旧库摘要校验失败，启动在设置迁移处中止；现在摘要按 LF 归一化计算，旧库记录的 LF/CRLF 两种历史摘要都接受并回写规范值，真正的 SQL 改动仍会被拒绝。包含 0.18.4 的全部内容。

0.18.1（2026-11-22）：安装包在安装/升级/修复/卸载开始前自动关闭正在运行的 Mosaic（先尝试正常退出保存数据，5 秒无响应才强制结束，只针对安装目录内的进程），正常情况下不再弹出「正在使用的文件」选择框；修复在非系统盘（如 E 盘）安装升级时「正在删除备份文件」阶段报「无法设置文件 E:\Config.Msi\xxx.rbf 的文件安全，错误 5」并中断安装的问题——安装包不再生成引擎回滚备份，失败后重新运行安装包即可继续完成未写入的文件；同版本维护扫描发现缺失或损坏时恢复自动修复（显式 /f 仍优先）。包含 0.18.0 的全部内容。

0.18.0（2026-11-22）：任务附件——在任务详情中拖拽文件到附件区或点击选择即可加入附件（单文件不超过 50 MB、每任务最多 10 个，可在设置中调整），附件保存在本机附件目录并在详情列表显示文件名与大小；从任务详情把附件拖到文件夹或其他应用即可发送副本，按住 Shift 拖出为移动，外部接收成功后应用内的原件与记录一并删除。设置新增「归档附件清除天数」（设置 → 任务，默认 0 表示不自动清除，可选 1–365 天），归档满指定天数的任务附件由后台每分钟检查并自动删除数据库记录与文件。包含 0.17.12 的全部内容。

0.17.6（2026-11-20）：修复完整界面安装停在空白「正在处理，请稍候」页面——进度页改为非模态对话框，界面序列不再被它阻塞，执行阶段正常启动；进度条与当前操作改为订阅安装引擎的 `SetProgress`/`ActionText` 事件，安装期间显示真实进度与动作文字。进度页的「取消」改为先弹出确认：选择「否」继续安装，选择「是」通知安装引擎取消并回滚。静默安装与健康维护提前结束的行为不变。包含 0.17.5 的全部内容。

0.17.4（2026-11-20）：同版本「检查与修复」的行为收口——再次双击同版本安装包后自动开始只读扫描，不再需要先点「下一步」；全部完好时直接显示「安装完整，无需修复」，「完成」在进入写文件的执行阶段之前结束，不会运行修复事务；只有发现缺失或损坏（或调用方显式传入 `/f`）才继续到 Windows Installer 修复并复检。结果分三种状态如实显示：「修复已完成」「需要重启后完成修复」（被占用文件安排到重启后替换，保留 3010）与「修复未通过复检」；静默安装的扫描或复检失败现在返回 1603 而不是 0，失败原因写入诊断日志。维护结果页可「重新检查」。包含 0.17.3 的全部内容。

0.17.3（2026-11-20）：安装器可自选安装位置并自带「检查与修复」——首次安装可通过路径输入、浏览或「恢复默认」指定位置（默认 `%LOCALAPPDATA%\Programs\Mosaic`），桌面与开始菜单快捷方式始终指向最终目录；同一版本已安装后再次运行安装包会自动扫描程序文件，全部完好时只提示无需修复，不重装也不关闭正在运行的程序，缺失或损坏时才通过 Windows Installer 修复并复检。安装包内嵌原生扫描器与载荷清单（相对路径、大小、SHA-256、组件映射），不依赖安装目录中的程序或清单，可执行文件、运行时 DLL 或整个安装目录被删除后仍能恢复；扫描只读，用户数据、凭据、配置与备份不受影响。升级原地继承登记位置，「应用和功能」与注册表登记实际安装目录。包含 0.17.2 的全部内容。

0.17.1（2026-11-20）：修复 0.17.0 安装后无法启动的问题——启动模块前误释放了单次使用的模块运行时并解绑模块事件，导致每次启动都以「Mosaic · 无法启动」诊断窗结束；同时修复应用内「修复安装」完成后应用不重新启动（默认的可执行文件路径指向不存在的 `Mosaic.exe`，改为当前进程路径）。「修复安装」现在先做只读配置检查：配置正常时提示「配置正常，无需修复」且不调用 Windows 安装程序，检测到配置问题（配置无效、能力绑定无效、有待应用的配置迁移）时先列出问题，确认后才执行修复。包含 0.17.0 的全部内容。
