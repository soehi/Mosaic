# Mosaic 0.5.0

Mosaic 0.5.0 聚焦设置架构收口和真实界面行为，继续保持任务、设置、存储、界面外壳与桌面驻留之间的模块化边界。

## 主要变化

- 宿主默认配置改为单一权威：设置页展示值与下次启动有效值一致，canonical 模块/provider 集合由内置模块清单推导。
- ModuleList 与 ProviderMap 共用公开格式、解析和比较规则；ProviderMap 顺序变化不再被误判为修改。
- 宿主配置与 SQLite 设置通过提交日志协调，启动时可幂等恢复中断的同批提交；恢复失败会显示明确配置诊断。
- 设置定义携带自己的显示名、描述和选项资源键；设置页不再维护全局模块 ID 翻译表。
- 导航由模块贡献的本地化键驱动；Shell 不再识别任务或设置的业务 ViewId。
- 任务错误、Shell 对话框和宿主诊断补齐中英文文字键。
- 任务紧凑布局改为真实单栏：窄窗口一次只显示列表或编辑器，并保留返回、草稿和离页保护。
