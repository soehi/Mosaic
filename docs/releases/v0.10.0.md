# Mosaic 0.10.0

Mosaic 0.10.0 · 更新日期 2026-11-17
适用范围：首次使用 → 0.10.0

新增功能
1. 任务速览圆圈可标记完成或恢复未完成，使用真实提交回执并刷新筛选结果。
2. 速览增加全部、未完成、已完成三段会话筛选；新增两个可预览的普通展示开关。

功能改进
1. 任务标签的标题、状态文字和内边距保留拖出入口，完成按钮和筛选控件独立交互。
2. 完成操作提供忙碌、重复点击保护、冲突刷新、可关闭错误提示与中英文无障碍名称。

问题修复与兼容变化
1. 快速切换筛选取消旧查询并忽略迟到结果；关闭速览取消在途操作。
2. 旧设置缺少新增开关时默认开启；无需迁移数据库、配置或浮窗记录。

## 定位与兼容

- 根因：`TaskPeekView.xaml` 的左侧 Path 只显示状态；`TaskPeekRow` 缺少 Revision，`TaskPeekViewModel.LoadAsync` 固定使用弹窗初始筛选，因此不能提交完成或会话筛选。筛选必须监听 Checked，才能统一鼠标、键盘和 UI Automation SelectionItem 的操作。
- 改动：`TaskPeekViewModel.CompleteAsync/SubmitCompletionAsync/SelectFilterAsync/LoadAsync/CloseAsync` 实现公开 API 提交与取消、冲突刷新和会话筛选；`TaskPeekView.xaml/.cs` 拆分操作与拖动控件；Presence 设置/本地化/Surface 和 `CompanionViewOptions` 传入展示选项；Tasks 中英文资源同步。逐个文件（含新增测试、版本、锁文件和文档）见 [文件清单](v0.10.0-files.md)。
- 旧安装无需配置、数据库或模块装配迁移，新增开关缺失时默认开启；旧任务、设置与浮窗记录保留。临时筛选不写入持久化。

- 最终验证（2026-11-17）：Release 构建 0 警告/0 错误；非桌面测试 171/171（WPF 67/67）通过；最终自包含 EXE 的速览桌面 Smoke 1/1 通过，完成/恢复后按筛选移除，重开数据库确认原任务 Revision 1→3、最终未完成。MSI 打包与桌面快捷方式数据库检查通过。安装包 51,974,276 字节，SHA-256 `466689E2640F916D3AB7A725D81C4482EB0A4601DA76184160F1322C4A787963`，版本 0.10.0；EXE FileVersion 0.10.0.0。MSI 使用 `-SkipValidation`，本轮没有执行真实安装升级或完整桌面矩阵。
