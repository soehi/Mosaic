# Mosaic 0.14.0

Mosaic 0.14.0 · 更新日期 2026-11-19
适用范围：首次使用 → 0.14.0

新增功能
1. 任务速览浮窗在进入备注编辑前，备注正文空白、底部按钮周边与标题下方空白都可以直接拖动窗口；文字上拖动仍用于选择文字，按钮、滚动条与编辑态保持原交互。
2. 新增“任务速览入口显示时机”设置：关闭主窗口后出现（默认）、最小化后出现、一直显示。

功能改进
1. 任务速览入口按所选时机在主窗口关闭驻留、最小化或可见时显示或隐藏，恢复主窗口后自动收起。

问题修复与兼容变化
1. 重新创建主窗口时不再沿用上一个窗口应用过的布局设置快照，避免侧栏宽度等布局值从旧实例带到新实例。
