# Mosaic 0.16.4 交付文件清单

本版本交付三条界面改进：账户页服务器地址默认建议官方实例、窗口右下角新增账号状态栏、左侧导航图标统一为 Segoe MDL2 Assets。不改 `server/`、`mobile/`。

## 根因位置

1. **默认服务器地址**：`src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AccountViewModel.cs`（0.16.3 版 :139）构造函数 `_serverInput = ServerText`，而 `ServerText`（:194）在未配置服务器时为空字符串——全新安装打开账户页时服务器输入框空白，用户必须先找到官方实例地址才能连接。本次把输入框默认值改为 `AuthValidation.DefaultServerUrl = "https://mosaic.bansonic.top"`；该默认值仅预填输入框，`auth.serverUrl` 设置默认值仍为空，不自动联网、不影响既有安装。
2. **账号显示**：`src/Mosaic.Shell.Wpf/ShellWindow.xaml`（0.16.3 版）内容区只有「导航行 + 内容行」两行，没有任何状态栏区域——登录状态只能打开账户页才能看到，窗口右下角无信息。本次在 presentation 契约层新增 `IStatusContribution`，Shell 泛化渲染、不引用 Auth 契约，保持「Shell 不写 if(auth)」的架构约束。
3. **导航图标**：`src/Mosaic.Shell.Wpf/NavigationConverters.cs`（0.16.3 版）把各模块的图标名映射到风格不一的字形（文本 `✓`、Unicode 杂项符号），`ShellWindow.xaml` 还内嵌一个手绘 `Path`（Settings 齿轮），大小、描边、明暗主题对比度不统一。本次统一映射为 Segoe MDL2 Assets 矢量字形，删除手绘 Path。

## 对已有安装的影响

- 无数据目录、配置文件、安装升级或模块装配改动；无需迁移逻辑与迁移验收项。
- `auth.serverUrl` 设置默认值仍是空字符串：未配置过的安装打开账户页会在输入框看到官方实例建议，可一键保存连接或改填其他服务器；已保存过地址的安装输入框仍显示自己的地址，行为不变。
- `IUiModule.Status` 为默认接口成员，第三方/其他模块不实现也能编译运行；无状态贡献时状态栏整体折叠，不改变既有窗口布局。
- 导航图标只是渲染层字形变化，导航契约（`NavigationItem` 的 `Icon` 名字段）不变。

## 未改动

- `server/`、`mobile/`。
- WiX/MSI 安装逻辑（`build/installer/Package.wxs`）、数据库表结构、既有设置键、导航契约、`appsettings.json`、`auth-sync-v1` 迁移。
