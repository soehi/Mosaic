# Mosaic 0.6.0

Mosaic 0.6.0 · 更新日期 2026-11-16
适用范围：首次使用 → 0.6.0

新增功能
1. 每个工作空间首次运行新发布版本时，自动生成一条未完成的“更新简要”任务；首次上线只介绍当前版本，跨版本升级合并未公告变化。
2. 任务模块增加通用原子创建一次能力；任务和创建回执在同一事务保存，编辑、完成或删除更新任务都不会使同版本重复生成。
3. 任务分区增加“自动生成更新简要”开关；保存后下一次启动生效，预览和开发调试不会创建任务。

功能改进
1. 任务速览改为紧凑只读列表、小型矢量状态、数量摘要和轻量操作区；长标题限制行数并保留全文提示和无障碍名称。
2. 速览按内容自然收缩并受最大高度和工作区限制，仅任务列表滚动，标题与底栏始终可见。
3. 新增按内容收缩、外层间距、圆角、行距、行内边距、字号、标题行数、状态文字和常驻提示九项高级视觉设置，支持可逆预览。
4. 发布说明与包内发布清单使用同一结构化内容源，校验版本、稳定发布身份、历史关系、正文指纹与默认任务限额。

问题修复与兼容变化
1. 速览更多菜单及提示纳入同一交互区域；Esc 先关闭菜单，避免点击退出入口时面板提前收起。
2. 内容、主题、字体、DPI、工作区和预览变化合并重测，旧会话关闭后不再移动新弹窗。
3. 已有数据目录在任务与设置依赖已启用时一次性接入更新模块，保持实际生效配置自洽；任务回执表通过存储迁移创建，原配置和任务数据保留。
4. 更新生成失败不阻塞主程序启动，不标记成功；读取回执失败、历史缺失或用户限额不足时记录诊断并在下次启动重试，不截断正文。
5. 多屏、100–200% DPI、高对比度实机、干净 Windows 安装升级等环境验收仍以实施记录为准，不宣称全部矩阵完成。
