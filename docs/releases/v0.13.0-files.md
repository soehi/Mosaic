# Mosaic 0.13.0 交付文件清单

## 契约与核心

- `src/Modules/Tasks/Mosaic.Tasks.Contracts/TaskRequests.cs`：`TaskItemDto` 增加完成/归档/恢复时间与 `IsArchived`；新增 `TaskArchiveScope`、`SetTaskArchivedRequest`；`ITasksApi` 增加 `SetArchivedAsync`。
- `src/Modules/Tasks/Mosaic.Tasks.Persistence.Contracts/ITaskRepository.cs`：新增 `QueryArchiveCandidatesAsync`。
- `src/Modules/Tasks/Mosaic.Tasks.Core/Internal/TaskService.cs`：创建与一次性创建写入完成时间；完成切换更新时间；新增 `SetArchivedAsync`；归档任务拒绝普通编辑。
- `src/Modules/Tasks/Mosaic.Tasks.Core/Internal/GuardedTasksApi.cs`：校验并转发归档请求。
- `src/Modules/Tasks/Mosaic.Tasks.Core/Internal/TaskSettingsSource.cs`：注册 `tasks.archive.autoEnabled` 与 `tasks.archive.delayDays`，应用时驱动归档策略。
- `src/Modules/Tasks/Mosaic.Tasks.Core/Internal/TaskAutoArchive.cs`：新文件，按时间提供器轮询到期任务并批量归档。
- `src/Modules/Tasks/Mosaic.Tasks.Core/TasksModule.cs`：激活/停止时同步归档策略。

## 存储

- `src/Modules/Storage/Mosaic.Tasks.Sqlite/TasksSqliteModule.cs`：注册 `003_TaskArchiving` 迁移。
- `src/Modules/Storage/Mosaic.Tasks.Sqlite/Migrations/003_TaskArchiving.sql`：新文件，为三列时间、旧数据回填与到期索引。
- `src/Modules/Storage/Mosaic.Tasks.Sqlite/Internal/SqliteTaskRepository.cs`：插入、更新、查询、映射与候选查询支持归档字段。

## 界面

- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TasksViewModel.cs`：归档筛选、归档/恢复命令、只读状态、外部归档保护。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Views/TasksView.xaml`：筛选增加“已归档”。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Views/TaskEditorView.xaml`：归档任务只读提示与归档/恢复按钮。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TaskFloatingContentFactory.cs`：归档任务浮窗恢复时拒绝打开、运行时转为只读。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TaskFloatingNotesViewModel.cs`：归档任务禁止编辑并保护草稿。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TaskFloatingDetailsView.cs`：归档状态禁用编辑入口。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Localization/zh.xaml`、`en.xaml`：归档双语资源。
