# Mosaic 0.16.4

Mosaic 0.16.4 · 更新日期 2026-11-19
适用范围：首次使用 → 0.16.4

新增功能
1. 窗口右下角新增状态栏，显示当前登录账号：登录时显示账号显示名与邮箱，未登录时显示「未登录 · 离线」；点击状态栏可直接打开账户页，状态栏随主题与紧凑侧栏自动调整，不占用主内容区。

功能改进
1. 账户页服务器地址默认建议改为官方实例 https://mosaic.bansonic.top：全新安装打开账户页时输入框已预填该地址，可直接保存连接，也可以改回其他 HTTPS 自建服务器；默认值只是输入建议，不会自动联网，已保存过服务器地址的安装不受影响。
2. 左侧导航图标统一为 Segoe MDL2 Assets 矢量字形（任务、已归档、设置、账户），大小与描边一致，明暗主题下对比度统一，选中态更清晰，替换掉原先风格不一的手绘图标。
