# Mosaic 0.17.6

Mosaic 0.17.6 · 更新日期 2026-11-21
适用范围：首次使用 → 0.17.6

功能改进
1. 完整界面安装的进度页改为非模态并订阅安装引擎事件，显示真实当前操作与进度，不再停在空白“正在处理，请稍候”页面。
2. 进度页的取消改为弹出确认对话框：选择“否”继续安装，选择“是”通知安装引擎取消并回滚。

问题修复与兼容变化
1. 修复完整界面安装卡在空白进度页：进度页此前为模态对话框，阻塞界面序列，导致执行阶段永远不被启动；现在进度页在界面序列中返回后由执行阶段驱动，安装可正常完成。
2. 修复进度条与当前操作不更新：进度条订阅 SetProgress、当前操作文字订阅 ActionText，执行期间显示真实进度。
3. 修复自选安装位置的完整界面安装丢失 156 个语言资源文件：子目录此前按默认 %LOCALAPPDATA% 路径解析，资源文件落进默认目录，维护扫描误报缺失并导致安装失败；现在每个语言子目录在执行序列按最终安装位置重新解析。
4. 修复安装成功后的完成页以「安装已取消」结束并返回错误码 1602：完成与健康维护提前结束此前使用 EndDialog Exit（用户取消语义），改为 EndDialog Return（正常成功）。
5. 修复损坏自动修复不复制任何文件：界面序列设置的修复请求（REINSTALL=ALL）不会传入安装服务端会话，现在由执行序列在成本计算前于服务端会话内落地；显式 /f 优先。
6. 以上修复均已在隔离环境完整界面实机验收：0.17.5 卡死复现、0.17.6 安装/健康维护/损坏修复/升级/取消回滚/静默回归共 8 个场景全部通过，真实安装与数据零改动。
