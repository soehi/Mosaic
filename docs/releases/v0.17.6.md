# Mosaic 0.17.6

Mosaic 0.17.6 · 更新日期 2026-11-20
适用范围：首次使用 → 0.17.6

功能改进
1. 完整界面安装的进度页改为非模态并订阅安装引擎事件，显示真实当前操作与进度，不再停在空白“正在处理，请稍候”页面。
2. 进度页的取消改为弹出确认对话框：选择“否”继续安装，选择“是”通知安装引擎取消并回滚。

问题修复与兼容变化
1. 修复完整界面安装卡在空白进度页：进度页此前为模态对话框，阻塞界面序列，导致执行阶段永远不被启动；现在进度页在界面序列中返回后由执行阶段驱动，安装可正常完成。
2. 修复进度条与当前操作不更新：进度条订阅 SetProgress、当前操作文字订阅 ActionText，执行期间显示真实进度。
