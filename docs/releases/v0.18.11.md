# Mosaic 0.18.11

Mosaic 0.18.11 · 更新日期 2026-11-24
适用范围：首次使用 → 0.18.11

新增功能
1. 速览的最近筛选改由设置库保存，作为隐藏的本机偏好与「速览默认筛选」分开管理。取值包括「尚未选择」「全部任务」「未完成」「已完成」；显示筛选切换时优先最近选择，隐藏筛选切换时始终使用默认筛选。设置页仍只显示默认筛选一项。
2. 本次发布同时包含 0.18.10 的内容：账户与备份页补齐空状态、刷新时保留已有会话行并对齐操作按钮；任务列表与速览使用圆角状态徽标和矢量回形针显示完成状态与附件。

功能改进
1. 设置提交改为可等待：驻留模块完成弹窗重建、布局更新和刷新后才把保存报告为成功，保存结果与界面状态不再错位。
2. 驻留模块只在影响弹窗结构或窗口位置的设置变化时刷新和重新定位，关闭行为、悬停延迟等无关设置不再触发弹窗重建；刷新失败写入诊断日志，不再以对话框打断设置操作。
3. 筛选变化与设置编辑互不覆盖：设置编辑会话中未提交的草稿保持不变，切换速览筛选也不会改动其他设置。
4. 「账户与备份」「维护」等模块贡献页不再显示通用「高级设置」栏；以隐藏代替折叠保留其占位高度，切换分区时导航与内容区坐标保持不变。

问题修复与兼容变化
1. 0.18.10 的速览最近筛选绕过设置模块，直接读写数据目录下的 Config/task-peek-filter.txt：无法纳入设置库的备份、迁移与重置，也没有区分「尚未选择」与「默认筛选」。现在读写统一走设置库的隐藏本机偏好，首次安装从「尚未选择」开始，运行时回退到默认筛选。
2. 已有安装的 task-peek-filter.txt 在启动时按迁移 ID 幂等导入一次：只接受 All、Open、Completed，设置库已有值时保留已有值；迁移失败不阻断启动，下次启动以同一迁移 ID 重试，旧文件始终保留，可在确认新值后删除。
3. 18 项驻留设置的显示名与说明注册在旧的小写点分键下（如 Settings.Setting.desktop.closeBehavior），而设置页按 Settings.Setting.Desktop.CloseBehavior 查找，这些行显示原始键名且缺少说明。现在文案由单一权威表生成，键与设置定义一一对应，并补齐「尚未选择」的中英文文案。
4. 驱动速览筛选变化的通知此前只能通过基础伴随视图接口订阅，宿主无法判断实现是否支持选择；现在提供可选接口 ICompanionFilterSelection，支持时通过它订阅，未实现时自动回退到基础接口的默认事件。CompanionViewOptions 与现有伴随视图实现保持不变。
