# Mosaic 0.17.4

Mosaic 0.17.4 · 更新日期 2026-11-20
适用范围：首次使用 → 0.17.4

新增功能
1. 维护页新增「重新检查」按钮：在结果页即可重新做只读扫描，不退出安装程序，也不需要重装。

功能改进
1. 双击同版本安装包后自动开始扫描，不再需要先点一次「下一步」；健康时直接显示「安装完整，无需修复」，只列出检查结果与安装位置。
2. 健康结果页的「完成」在进入写文件的执行阶段之前结束安装，不再走修复事务；只有发现缺失或损坏、或调用方显式传入 /f 时才继续到修复并复检。
3. 修复过程中在进度页显示扫描摘要，完成后结果页分别显示「修复已完成」「需要重启后完成修复」与「修复未通过复检」，不再用同一句完成提示覆盖三种状态。

问题修复与兼容变化
1. 修复静默安装以 0 返回失败：扫描无法读取安装目录、载荷清单损坏或安装位置无法确认时，/qn 现在返回 1603 并写入诊断日志，不再只把原因写入属性。
2. 修复修复后复检失败仍被当作成功：复检未通过时安装以失败结束并落到错误页，不再显示完成页。
3. 被占用而安排到重启后替换的文件单独归类为「待重启」并保留 3010，重启前哈希不符不再被报成修复成功，也不误报为失败。
4. 显式 /f 的修复语义保持原样：扫描健康时不清除调用方设置的 REINSTALL，也不会被健康结果页提前结束。
