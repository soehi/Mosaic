# Mosaic 手机端 0.3.3

Mosaic 手机端 0.3.3 · 更新日期 2026-11-27
适用范围：0.3.2 → 0.3.3 覆盖安装，或全新安装
平台：Android（`minSdk 26`、`targetSdk 36`）；桌面端与服务端不随本版本发布
包名：`app.mosaic.tasks`；`versionCode=8`

## 长按切换任务组

长按小组件卡片 → 系统菜单出现「编辑」铅笔 → 进入任务组选择，四个选项：**未完成 / 已完成 / 已归档 / 全部**，当前组带勾。选完立即生效并关闭，取消不改动。

这是 Android 平台唯一受支持的长按路径。AppWidget 的长按手势由 launcher 持有，`RemoteViews` 没有 long-click API，应用无法拦截原始 long-press 事件；实现用的是 `android:configure` + `android:widgetFeatures="reconfigurable|configuration_optional"`，没有透明遮罩、没有伪造长按检测、没有用点击模拟长按。

- 分组按 `appWidgetId` 独立保存，同一桌面上的两个小组件可以显示不同的组。
- 「已完成」「已归档」两组是只读列表：圆圈显示为实心主色带勾，点它不产生任何写操作。
- 「未完成」与「全部」两组可点圆圈完成任务；「全部」组里完成后该行留在原位、圆圈变实心。
- 每组的空态文案不同：暂无未完成任务 / 暂无已完成任务 / 暂无归档任务 / 暂无任务。
- 删除小组件时一并清理它的分组设置。

## 修复

- **点已完成行的圆圈会误标另一条任务**：列表行视图被回收时，没写点击意图的行继承了上一行的任务 id。现在每一行都携带自己的 id 与只读标记，只读行在接收端直接丢弃。
- **配置入口启动不到**：`android:configure` 里写的 Java 类名与生成的包装类名不一致，launcher 点了没有反应。已用 `Activity(Name = ...)` 钉死为 `app.mosaic.tasks.WidgetConfigActivity`。
- **深色模式勾不可辨**：完成勾的颜色改为 `widget_on_primary`（浅色白 / 深色 `#1F1F1F`）。

## 升级与迁移

- 0.3.2 的行快照没有版本号、只有三个字段。升级后首帧按旧格式迁移为「未完成」行，卡片不会空白；首次同步后重写为 v4 格式。
- 分组设置写在新的 `widget_prefs` 文件里，旧安装没有该键，默认「未完成」，行为与 0.3.2 一致。
- 已放置的小组件不需要重新添加。

## 已知限制

- 4 列宽在 360dp 宽的屏幕上仍被 launcher 封顶为 2 列，属设备限制。
- 长按能进入 launcher 的编辑菜单（可配置分组），但缩放手柄仍不可用。
- 流体云仍不可接入（无 OPPO 凭证与真机）。
- 真机 arm64 未验证；宽屏 4×1/4×2 的实际格数未验证。

## 回滚

`git revert <0.3.3 提交>`；设备侧 `versionCode` 不能从 8 回退到 7，需卸载后安装 0.3.2。
