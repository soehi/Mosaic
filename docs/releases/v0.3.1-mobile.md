# Mosaic 手机端 0.3.1

Mosaic 手机端 0.3.1 · 更新日期 2026-11-27
适用范围：0.3.0 → 0.3.1 覆盖安装，或全新安装
平台：Android（`minSdk 26`、`targetSdk 36`）；桌面端与服务端不随本版本发布
包名：`app.mosaic.tasks`；`versionCode=6`

## 修复

- **桌面小组件显示“载入窗口小部件出现问题”**：布局里的分隔线用了原生 `<View>`，而 `RemoteViews` 只接受白名单类型，launcher 在 apply 时抛 `InflateException`。已换成 `TextView` 分隔线，并在渲染外包 try/catch，失败时退回只含标题与刷新的安全布局。
- **小组件一直停在“正在同步”**：`TaskWidgetProvider` 曾声明 `exported="false"`，系统 `AppWidgetService`（不同 UID）发出的 `ACTION_APPWIDGET_UPDATE` 无法投递，`onUpdate` 从不执行。已改为 `exported="true"`，`OnReceive` 只放行系统 widget 动作。
- **进程启动即崩溃（`UnsatisfiedLinkError: ... n_onCreate`）**：`PublishTrimmed=false` 与该 SDK 的装配体类型注册冲突。已改为开启 trimming、保留内核程序集并显式启用 JSON 反射；APK 体积从约 21 MB 降到约 5 MB。
- **行数不受控**：`AppWidgetOptions` 给出的是像素，旧实现当 dp 用。已按显示密度换算后分档（≥220dp→5 行、≥170→4、≥140→3、≥100→2）。

## 小组件尺寸

改为 **4 列 × 2 行**（`minWidth=250dp`、`minHeight=110dp`、`targetCellWidth=4`、`targetCellHeight=2`），保留横向/纵向缩放，最小可缩到 110dp × 110dp。根内边距 8dp、行高 26dp，窄于 180dp 时按钮改用单字标签，保证“标题 + 完成 + 归档”同行显示。

## 测试包（非正式发布）

带 `-p:MosaicWidgetTestSeed=true` 构建的测试包内置 6 条中文假任务（4 条未完成、1 条已完成、1 条已归档，含一条长标题），用于在没有服务器和登录的情况下查看卡片：

```powershell
adb shell am broadcast -a app.mosaic.mobile.action.SEED_TEST -n app.mosaic.tasks/crc646217c2ecd9b8e14f.TestSeedReceiver
```

种子写在独立偏好 `mosaic.mobile.v3.testseed`，不写投影目录、不伪造登录态；详情行固定显示“测试数据”，完成/归档的 toast 也以“测试数据”开头。**正式 Release 构建不包含该类型与广播。**

## 已知限制

- 流体云仍不可接入（无 OPPO 凭证与真机），卡片显示“不可用”，未用 AppWidget 冒充。
- 4×2 实例在 MuMu 的 Lawnchair 上会保留底部空白；新实例的实际行数与裁切需真机复核。
- 「任务提示」只做常驻展示，不做定时提醒。

## 回滚

`git revert <0.3.1 提交>`；设备侧 `versionCode` 从 6 回退到 5 不允许覆盖安装，需卸载后安装 0.3.0。
