# Mosaic 0.17.1

Mosaic 0.17.1 · 更新日期 2026-11-20
适用范围：首次使用 → 0.17.1

功能改进
1. 设置内的「修复安装」先做只读配置检查：配置正常时提示「配置正常，无需修复」且不调用 Windows 安装程序，检测到问题（配置无效、能力绑定无效、有未应用的配置迁移）时先列出问题，确认后才修复

问题修复与兼容变化
1. 修复 0.17.0 安装后无法启动：启动模块前释放了单次使用的模块运行时并解绑模块事件，每次启动都以「Mosaic · 无法启动」诊断窗结束；恢复启动失败时统一清理并记录错误编号的结构
2. 修复应用内「修复安装」完成后应用不重新启动：默认的可执行文件路径指向不存在的 Mosaic.exe，改为当前进程路径
