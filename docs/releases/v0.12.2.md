# Mosaic 0.12.2

应用内按钮在鼠标松开后立即结束按压反馈。指针仍在按钮上时显示悬停样式，移开后恢复常态。使用 Tab 或 Shift+Tab 导航时，键盘焦点由按钮下方的小标记提示。

任务浮窗的置顶状态由空心和实心图钉表示。任务速览筛选、设置开关、导航选择和浮窗备注编辑继续使用各自的状态样式。新版可直接读取已有任务、配置和浮窗记录。
