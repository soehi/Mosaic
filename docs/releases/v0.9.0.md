# Mosaic 0.9.0

Mosaic 0.9.0 · 更新日期 2026-11-17
适用范围：首次使用 → 0.9.0

新增功能
1. 新增顶部拖动带、卡片内边距和内容间距三个高级设置，支持保存前可逆预览。

功能改进
1. 悬浮任务窗工具与任务内容共用首行，移除独立工具栏和固定空白高度，长标题按内容换行增长。
2. 移动、缩放及光标共用命中规则：可见顶边与顶部圆角移动，侧边下部和底边缩放，工具和正文保持原有交互。

问题修复与兼容变化
1. 修复只能点中拖动标记才可移动的问题；透明外侧、禁用按钮、正文选择和滚动区域不会误触拖动。
2. 沿用既有布局保存和退出恢复管线，密度预览不改写窗口尺寸偏好；无需配置或数据库结构迁移，旧配置缺失项采用默认值。

## 兼容与验证

- 已有安装直接升级；用户数据目录、数据库表、窗口记录和现有配置结构不变。
- 本机 Release 构建通过，0 警告、0 错误；非桌面自动化 166/166 通过，其中 WPF 62/62。
- 悬浮窗正常恢复、独立关闭和正常退出重启 Smoke 通过；真实指针路径验证顶部移动、圆角移动、侧边缩放、工具区域排除和位置恢复。
- 100–200% DPI、多屏、高对比度实机矩阵和干净 Windows 安装升级仍需独立环境验收。
