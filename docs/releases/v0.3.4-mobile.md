# Mosaic 手机端 0.3.4

Mosaic 手机端 0.3.4 · 更新日期 2026-11-27
适用范围：0.3.3 → 0.3.4 覆盖安装，或全新安装
平台：Android（`minSdk 26`、`targetSdk 36`）；桌面端与服务端不随本版本发布
包名：`app.mosaic.tasks`；`versionCode=9`

## 修复

### 可见行数不符（主问题）

0.3.4 根据宿主尺寸计算行数，并将列表数据截断为最多两条。`TaskWidgetService` 的 `.Take(_layout.Rows)` 使第三条及之后的任务无法滚动到达。计算得到的像素高度没有应用到行或视口，实际完整可见行数未经设备验收。

### 重装后黑块

`TaskWidgetService` 的非导出状态会影响跨进程绑定。重装黑块的根因尚缺同一设备的对照验证。

**修法**：`TaskWidgetService` 改为 `Exported = true`（`BIND_REMOTEVIEWS` 权限仍在，仅系统/特权 launcher 可绑定）。

## 升级与迁移

- 分组偏好 `widget_prefs` 与快照格式不变。
- 升级后首次刷新自动重新计算行数。
- 回滚需卸载（`versionCode` 不能从 9 回退到 8）。

## 已知限制

- 4 列宽在 360dp 宽的屏幕上仍被 launcher 封顶为 2 列，属设备限制。
- 长按能进入编辑菜单（可配置分组），但缩放手柄仍不可用。
- 流体云仍不可接入（无 OPPO 凭证与真机）。
- 真机 arm64 未验证；宽屏 4×1/4×2 的实际格数未验证。
- 本次修复的端到端验证因 MuMu 模拟器 adb 服务不可用而阻塞，单元测试 81 项通过。

## 回滚

`git revert <0.3.4 提交>`；设备侧 `versionCode` 从 9 回退到 8 不允许覆盖安装，需卸载后安装 0.3.3。
