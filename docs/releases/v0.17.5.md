# Mosaic 0.17.5

Mosaic 0.17.5 · 更新日期 2026-11-20
适用范围：0.17.4 → 0.17.5（也适用于更早版本升级）

问题修复与兼容变化
1. 修复自定义安装位置卸载后文件残留：卸载会话此前不会执行状态检测，`INSTALLFOLDER` 退回包内默认目录 `%LOCALAPPDATA%\Programs\Mosaic`，Windows Installer 只删除默认目录中的文件，自定义位置的全部程序文件被遗留。0.17.5 在成本核算（CostFinalize）之前从产品登记的安装位置恢复 `INSTALLFOLDER`，卸载后自定义目录中的程序文件与空目录一并移除。未登记安装位置的 0.17.2 及更早版本仍按默认目录语义卸载。
2. 修复扫描与修复动作未关闭 Windows Installer 数据库句柄：每次只读扫描或修复复检都会在安装日志中留下 `DEBUG: Error 2769: Custom Action … did not close 1 MSIHANDLEs.` 警告。0.17.5 在读取完载荷清单后关闭 `MsiGetActiveDatabase` 返回的句柄，安装与维护日志不再出现该警告。

兼容性说明
1. 组件 GUID、KeyPath、UpgradeCode、per-user 安装范围、数据目录与注册表结构均未变化，升级由既有的 `MajorUpgrade` 原地完成，无需迁移。
2. 已登记安装位置的产品（0.17.3 及之后）在任何位置卸载都会按登记位置删除程序文件；`%LOCALAPPDATA%\Mosaic` 下的用户数据、凭据与配置不受影响。
3. 使用自定义位置的用户升级到 0.17.5 后无需重新指定位置，登记位置继续沿用。
