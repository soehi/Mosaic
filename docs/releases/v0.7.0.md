# Mosaic 0.7.0

Mosaic 0.7.0 · 更新日期 2026-11-16
适用范围：首次使用 → 0.7.0

新增功能
1. 速览任务支持鼠标或键盘打开面板内只读详情，显示完整标题、可选择复制的备注、状态及创建和更新时间。

功能改进
1. 任务块采用真正的按钮与稳定任务身份，提供悬停、按下及键盘焦点反馈；同名任务可分别查看。
2. 详情从公开任务 API 读取最新内容，支持加载、重试、删除反馈及返回列表；返回保留列表筛选、顺序、滚动和来源焦点。

问题修复与兼容变化
1. 详情请求带取消和代次保护，迟到响应不会覆盖新选择，返回或关闭后不会复活页面。
2. Esc 按菜单、详情返回、收起的顺序处理；阅读与文本选择期间保持交互，上下键由正文处理。
3. 本次无需配置和数据库迁移，设置仍为84项；实际拖出与多个置顶任务窗尚未交付。
