# Mosaic 0.18.0

Mosaic 0.18.0 · 更新日期 2026-11-22
适用范围：首次使用 → 0.18.0

新增功能
1. 任务附件：在任务详情中拖拽文件到附件区或点击选择即可加入附件（单文件不超过 50 MB、每任务最多 10 个，可在设置中调整），附件保存在本机附件目录并在详情列表显示文件名与大小。
2. 附件拖出：从任务详情把附件拖到文件夹或其他应用即可发送副本；按住 Shift 拖出为移动，外部接收成功后应用内的原件与记录一并删除。
3. 新建设置「归档附件清除天数」（设置 → 任务，默认 0 表示不自动清除，可选 1–365 天）：归档满指定天数的任务附件由后台每分钟检查并自动删除数据库记录与文件。
