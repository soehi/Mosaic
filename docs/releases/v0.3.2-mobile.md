# Mosaic 手机端 0.3.2

Mosaic 手机端 0.3.2 · 更新日期 2026-11-27
适用范围：0.3.1 → 0.3.2 覆盖安装，或全新安装
平台：Android（`minSdk 26`、`targetSdk 36`）；桌面端与服务端不随本版本发布
包名：`app.mosaic.tasks`；`versionCode=7`

## 小组件按 M2.5 重做

- **视觉**：12dp 圆角表面 + 1dp 柔和描边，浅色 `#FFFFFF` / 深色 `#1F1F1F`，单一主色 `#1A73E8`（深色 `#8AB4F8`）。不引入 Material Components 依赖。
- **结构**：卡片里只有一个任务列表，没有标题栏、没有刷新、没有归档按钮。
- **行**：52dp 高，左侧 24dp 完成圆圈（1.5dp 主色空心圆），右侧单行省略标题，行间 1dp 分隔线。
- **完成**：点圆圈 → 该行立即从列表移除，待办计数下降。走原有窄写 `POST /v1/sync/changes`；测试种子模式下本地更新并提示“测试数据”。
- **滑动**：改用 `ListView` + `RemoteViewsService`，这是 App Widget 唯一受支持的原生滑动手势；4×1 露 1 行、4×2 露 2 行，向上滑动浏览后续任务。
- **空列表**：显示“暂无任务”，没有任何按钮。
- **尺寸**：`minWidth=250dp`、`minHeight=40dp`、`targetCell 4×1`、纵向可缩放到 140dp、`resizeMode="vertical"`。

归档仍在底层命令里保留，但小组件上不再有入口。

## 已知限制

- **4 列宽在窄屏不可得**：`targetCellWidth=4` 已是正确声明，但 launcher 会把列数封顶到屏幕能容纳的数量（720px / density 2 = 360dp 只够 2 列）。宽屏真机才能看到 4 列。
- **长按缩放不可用**：`ListView` 消费了长按手势，launcher 进不了缩放模式。这是 ListView 型小组件的固有行为，不是配置遗漏。
- 流体云仍不可接入（无 OPPO 凭证与真机），卡片上不显示流体云状态。
- 真机 arm64 未验证。

## 回滚

`git revert <0.3.2 提交>`；设备侧 `versionCode` 从 7 回退到 6 不允许覆盖安装，需卸载后安装 0.3.1。
