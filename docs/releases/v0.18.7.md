# Mosaic 0.18.7

Mosaic 0.18.7 · 更新日期 2026-11-23
适用范围：首次使用 → 0.18.7

新增功能
1. 启动页由导航贡献声明默认页（`NavigationItem.IsDefault`），任务页成为唯一默认落点；工作区加载失败时显示错误图标与说明，不再留下没有内容的空白页。

功能改进
1. 账户页恢复已登录内容：账户信息、同步开关与会话列表按状态显示，只保留一个带辅助名称的退出按钮；登出或删除账户后清空会话、最近备份与上次恢复摘要，同步服务在未登录时不再返回上一账户的快照。
2. 设备码倒计时改用单调时钟，界面卡顿或服务端要求放慢轮询时不会漂移；同步开关的编辑会话串行提交，快速连点不会互相覆盖；切换语言或离开账户页再回来，服务器地址输入与离线选择保持不变。
3. 任务列表读屏改读完整无障碍标签，附件提示按数量播报（如「3 个附件」）；主题词典统一由调色板提供颜色，补齐可编辑下拉框、进度条轨道、禁用态复选框/单选按钮、换行提示框与带勾选/快捷键列的右键菜单。
4. 窗口标题栏的深浅色 chrome 迁入 Shell 程序集，主题切换从任意线程触发都切回窗口调度器，高对比度与已关闭窗口直接跳过；窗口位置按虚拟屏幕钳制，副显示器保存的位置不会在启动时被移回主屏或缩小。
5. 配置写回保持 `storage` 下 `engine` / `location` / `filename` 小写键，默认配置补上 `tasks.attachments@1` 能力绑定，健康安装不再在每次启动被重写。

问题修复与兼容变化
1. 未配置服务器时点击「在浏览器中登录」会停在服务器面板并提示需要服务器地址，不再静默使用官方实例。
2. 删除首次启动账户选择状态机：移除 `auth.accountChoiceMade` 设置与跨模块启动事件链，升级时自动删除旧库中的该设置行，其余设置与数据不变。
3. 修复主题测试与控件取色：测试宿主与预览单独加载主题词典时按运行时方式合并浅色调色板，禁用态背景与文字颜色可稳定解析。
4. 修复桌面 smoke 测试并行抢前台窗口、真实拖动断言不留系统拖动阈值余量的问题；WPF 测试补齐设备码 approved 登录态替身与登出用例顺序。
