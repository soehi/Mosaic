# Mosaic 0.14.0 交付文件清单

## 浮窗空白区拖动（需求一）

- `src/Mosaic.Presentation.Contracts/FloatingPresentation.cs`：新增 `FloatingContentDragKind` 与 `IFloatingContentSession.QueryContentDrag`。
- `src/Modules/FloatingWindows/Mosaic.FloatingWindows.Wpf/FloatingWindowInput.cs`：命中判定接入内容层拖动语义，Deferred 文本按下保持交互、超阈值原生移窗，Immediate 空白直接 HTCAPTION。
- `src/Modules/FloatingWindows/Mosaic.FloatingWindows.Wpf/FloatingSurface.cs`：向 `FloatingWindowInput` 传入内容视图与拖动查询。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TaskFloatingContentFactory.cs`：`TaskFloatingContentSession.QueryContentDrag` 坐标转换与转发。
- `src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TaskFloatingDetailsView.cs`：备注字形/空白/编辑态/按钮的拖动语义判定。

## 速览入口显示时机（需求二）

- `src/Modules/DesktopPresence/Mosaic.DesktopPresence.Contracts/PresenceContracts.cs`：`MainWindowPresentation`、`IDesktopWindowHost.CurrentPresentation`/`PresentationChanged`、`IDesktopPresenceSurface.SetEdgeVisibleAsync`。
- `src/Modules/DesktopPresence/Mosaic.DesktopPresence.Core/PresenceController.cs`：`ConfigureShowTiming` 与按时机评估入口显隐。
- `src/Mosaic.Desktop/DesktopWindowHost.cs`：主窗口状态上报。
- `src/Modules/DesktopPresence/Mosaic.DesktopPresence.Wpf/DesktopPresenceModule.cs`：设置值到时机集合的映射。
- `src/Modules/DesktopPresence/Mosaic.DesktopPresence.Wpf/PresenceSettings.cs`、`PresenceLocalization.cs`：新设置 `desktop.edge.showTiming` 及本地化。
- `src/Modules/DesktopPresence/Mosaic.DesktopPresence.Wpf/PresenceSurface.cs`：幂等 `SetEdgeVisibleAsync`。
