# Mosaic 0.16.5 交付文件清单

本版本重构登录/账号入口：左侧导航移除「账户」，账号入口移入左下角状态区并带退出登录，首启与退出后统一进入四选一账号选择页。不改 `server/`、`mobile/`。

## 根因位置

1. **账号入口位置与首启机制**：`src/Modules/Auth/Mosaic.Auth.Wpf/AuthUiModule.cs` 的 `Navigation` 属性此前注册 `account.navigation` 导航项，账号入口占据左侧导航栏；同一模块的 `src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AccountViewModel.cs` 另有一套 `StartView`/`ShowWelcomeLayout`/`SetThemeCommand` 首启欢迎布局（0.16.5-pre 提交 `616d9eb` 引入），与主内容区浅色视觉规范割裂，且形成第二套首启机制。
2. **左下角无账号状态与退出入口**：`src/Mosaic.Shell.Wpf/ShellWindow.xaml` 的状态面板（StatusPanel）此前只渲染右下角横向状态项，`IStatusContribution`（`src/Mosaic.Presentation.Contracts/PresentationContracts.cs`）没有「侧栏放置」与「动作按钮」概念，模块无法在左下角呈现账号卡片，也无法提供退出登录按钮。
3. **退出登录不清首启选择**：`AccountViewModel.LogoutAsync`（0.16.4 版 :658）与 `AccountStatusItem.SignOutAsync` 只撤销服务器会话，不清理 `auth.accountChoiceMade` 标记，退出后无法回到账号选择流程。

## 改动位置

### 契约扩展（通用，Shell 不感知 auth）

- `src/Mosaic.Presentation.Contracts/PresentationContracts.cs` — 新增公开枚举 `StatusPlacement { None, Bottom }`；`IStatusContribution` 新增可选成员（均带默认实现，二进制兼容）：`SidebarPlacement => StatusPlacement.None`、`CanAct => false`、`ActionGlyph`/`ActionLabel`/`ActionToolTip => null`、`event ActionRequested`（空 add/remove）、`void RequestAction()`。
- `build/public-api.txt` — 登记 `Mosaic.Presentation.Contracts.StatusPlacement`。

### 账号入口移入左下角 + 退出登录

- `src/Modules/Auth/Mosaic.Auth.Wpf/AuthUiModule.cs` — `Navigation => []`（移除 account.navigation）；`_statusItem = new AccountStatusItem(dependencies.Auth, dependencies.Settings, dependencies.Dialogs, dependencies.Dispatcher, dependencies.Diagnostics)`。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AccountStatusItem.cs`（全量重写）— `SidebarPlacement => StatusPlacement.Bottom`；`CanAct => IsSignedIn && !_signingOut`；`ActionGlyph`（MDL2 Leave）/`ActionLabel`/`ActionToolTip` 走本地化；`RequestAction()` → `SignOutAsync()`：`IUserDialogService.ConfirmAsync` → `IAuthApi.LogoutAsync`（保留本机任务，仅撤销服务器会话）→ `ClearAccountChoiceAsync()`（settings journal 提交 `auth.accountChoiceMade = null`）→ 触发 `ActionRequested` 请求 Shell 导航回 `account.home`；异常经 `IDiagnosticSink` 上报并提示；新增 `RequestActionAndWaitForIdleAsync()` 供测试等待完成。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AccountViewModel.cs` — 删除 `StartView` 枚举、`_startView`、`ShowWelcomeLayout`、`ThemeVariant`、`SetThemeCommand`、`SetTheme`、`OnThemeChanged`；新增 `ShowAccountChoice => IsSignedOut && !_offlineChosen && Mode == AccountMode.Login`；`LogoutAsync` 新增 `ClearAccountChoiceAsync()`（与状态卡片路径语义一致）；`ModeTitle`/`ModeDescription` 默认分支改用 `Auth.Choice.Title`/`Auth.Choice.Description`；`InitializeAsync` 简化为 `LoadSyncOptionsAsync` + `RefreshSummaries`；`UseOffline`/`Connect`/`NotifyAuth` 补 `ShowAccountChoice` 变更通知。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Views/AccountView.xaml` — 回退 welcome 双栏后重排登录区为四选一：浏览器登录（accent 按钮，`AutomationId="BrowserLoginButton"`）→ 邮箱/密码表单 → 登录按钮 → 链接行（离线使用 / 自建服务器 / 忘记密码）；登录容器加 `AutomationId="AccountChoice"`。服务器地址面板保留原位。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Internal/AccountConverters.cs` — 随 welcome 回退清理，仅保留 `LocalDateTimeConverter`/`CurrentSessionTagConverter`。
- `src/Modules/Auth/Mosaic.Auth.Wpf/Localization/zh.xaml`、`en.xaml` — 新增 `Auth.Choice.Title`、`Auth.Choice.Description`、`Auth.Logout.Confirm`、`Auth.Status.SignOut`、`Auth.Status.SignOut.Tooltip`。

### Shell 通用渲染与首启重定向

- `src/Mosaic.Shell.Wpf/ShellViewModel.cs` — `NavigateToViewAsync` 增加 `NavigateDirectAsync` 回退（无导航项也可按 viewId 直达）；首启重定向条件改为「registry 有 `account.home` && 未做账号选择 && `auth.serverUrl` 空白」→ `NavigateToViewAsync("account.home")`；新增 `SidebarStatusItems`（`SidebarPlacement == Bottom`）并在 `RebuildStatusItems` 中订阅每项 `ActionRequested`（触发后若 `TargetViewId` 非当前页则导航过去）；新增 `StatusActionCommand = RelayCommand<IStatusContribution>(item => item?.RequestAction())`；`DisposeAsync` 退订全部 handler。
- `src/Mosaic.Shell.Wpf/ShellWindow.xaml` — StatusPanel 顶部按 `SidebarStatusItems` 通用渲染左下角卡片（`AutomationId="SidebarStatusItem"` / `"SidebarStatusAction"`）；动作按钮 Visibility 用 MultiBinding `StatusActionAvailable(CanAct, ActionLabel, ActionGlyph)`；主按钮走 `NavigateToViewCommand(TargetViewId)`；紧凑侧栏隐藏文本。
- `src/Mosaic.Shell.Wpf/NavigationConverters.cs` — 新增 `StatusActionAvailableConverter`（IMultiValueConverter：CanAct 为 true 且 label 或 glyph 非空 → Visible）与 `StatusActionHiddenConverter`。

## 对已有安装的影响

- 无数据目录、配置文件、安装升级或模块装配改动；无需迁移逻辑与迁移验收项。
- 首启重定向要求 `auth.serverUrl` 为空白：0.16.4 及更早已配置服务器的安装不满足条件，启动后仍停留在上次的页面，行为不变（「仅配置服务器不算做过选择」语义由测试钉住）。
- 退出登录后清理 `auth.accountChoiceMade` 但保留已保存的服务器地址：本次会话立即回到账号选择页；下次启动因服务器地址仍存在不会强制重定向。
- `IStatusContribution` 新成员均为默认实现，其他模块无需改动；无 `Bottom` 放置的状态项时左下角不渲染卡片。
