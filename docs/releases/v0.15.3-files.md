# Mosaic 0.15.3 交付文件清单

## 自动归档启停测试补强

- `tests/Mosaic.Tasks.Core.Tests/AutoArchiveTests.cs`：
  - `Disabled_auto_archive_never_archives_due_completed_tasks` 更名为 `Auto_archive_disabled_policy_never_archives_due_completed_tasks`，候选任务改为 8 天前完成（等待期 7 天），并新增自动归档未启动的断言：反射读取 `_delayDays` 为 0、`_cancellation` 为 null、`_loop` 仍是 `Task.CompletedTask`。
  - `Enabled_auto_archive_archives_due_candidates_and_stops_when_disabled_again`：开启后断言 `_delayDays == 7`、`_cancellation` 非空；关闭后断言 `_delayDays == 0`、`_cancellation` 为 null，再验证新插入的超龄已完成任务不会被归档。
  - 新增辅助方法 `Field`（反射读取 `TaskAutoArchive` 的私有字段）。
