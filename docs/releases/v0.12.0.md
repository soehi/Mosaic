# Mosaic 0.12.0

Mosaic 0.12.0 · 更新日期 2026-11-18
适用范围：首次使用 → 0.12.0

新增功能
1. 浮窗设置新增“允许编辑浮窗详细内容”，默认关闭。开启后可编辑任务备注，保存后同步到任务列表。

功能改进
1. 浮窗的正文和按钮移除矩形描边，使用主题底色提示悬停、按下和键盘焦点。

问题修复与兼容变化
1. 关闭浮窗或退出应用时保护未保存的正文。保存失败、版本冲突或取消关闭时保留草稿。

## 升级与验证

已有工作空间缺少新设置时由 Settings 默认值合并读取为关闭。保存开关后通过现有用户设置持久化。任务和窗口恢复记录沿用原有格式。

详见[根因、改动位置与验收记录](../implementation-status.md)和[逐文件改动清单](v0.12.0-files.md)。
