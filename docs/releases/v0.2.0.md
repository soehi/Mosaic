# Mosaic 0.2.0

Mosaic 0.2.0 · 更新日期 2026-11-15
适用范围：0.1.0 → 0.2.0

新增功能
1. 增加模块化设置页，支持任务、外观与布局、存储与系统、文案分区，以及普通与高级参数。
2. 加入浅色、深色、高对比度主题和中英文界面。

功能改进
1. 设置支持整数、布尔、枚举、文本、模块和能力绑定编辑，保存、放弃、恢复默认和重启提示。
2. 启动尺寸、侧栏断点、页边距、存储队列、超时、备份保留、日志和单实例重试设置接入消费方。
3. 侧栏支持拖动调宽、键盘微调、图标模式和自动适应窗口；任务操作栏固定并支持窄窗重排。

问题修复与兼容变化
1. 统一值类型、宿主生效配置与跨字段校验，修复设置显示已保存但不生效及部分写入问题。
2. 修复主题层级、导航图标与激活态、字段和全局反馈残留、列表重试、冲突提示与忙碌反馈。
3. 单实例归一化数据目录，改为目录独占锁；强化启动失败回收、退出链异常安全、事务回调检查及迁移备份保留。

首个版本的完整说明、安装方式与验证记录见 `v0.1.0.md`（该文件同时覆盖 0.1.0 与 0.2.0）。
