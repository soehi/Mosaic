# Mosaic 0.10.2

Mosaic 0.10.2 · 更新日期 2026-11-18
适用范围：首次使用 → 0.10.2

功能改进
1. 速览整行都可作为拖出起点，包括完成按钮、状态文字与行内留白；拖动时以虚线框标出整个任务标签。
2. 速览筛选改为带轨道的分段控件，选中项使用表面色药丸，摘要与筛选同排并在窄宽度下自动截断。

问题修复与兼容变化
1. 点击任务标签仍打开详情、点击完成按钮仍切换状态；拖出仍只通过公开分离来源申请，模块边界与设置不变。

## 根因与改动

- 根因：`src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TaskPeekView.xaml:87`（0.10.1 基线）把手势处理器只绑在详情 Button 上，完成按钮和两列间留白不建立拖动候选；`DragHintAdorner` 只有文字提示，拖动时任务标签本身没有标记。`TaskPeekView.xaml:51–58` 的摘要与筛选放在 `WrapPanel`，按钮使用临时背景与边框，选中态和间距不一致。
- 改动：`TaskPeekView.xaml` 将鼠标处理器移到带透明背景的 `TaskRow`，筛选区改为“摘要 + 轨道”的 `Grid` 并重写 `PeekFilterButton` 模板；`TaskPeekView.xaml.cs` 的 `_candidate` 改为行容器，`StartGesture/ActivateDrag/FinishDrag` 接受行容器，`CaptureLost` 忽略子按钮交还捕获的冒泡事件，`CompleteTask` 尊重拖动抑制标记；`DragHintAdorner` 增加整标签虚线框并使用主题画笔；`TaskPeekViewFactory.cs` 改为遍历 `FilterOptions.Children`；`tests/Mosaic.Wpf.Tests/PresenceTests.cs` 覆盖四类拖出起点并新增窄宽度布局回归。
- 兼容：无设置、数据库、配置或模块装配迁移；无公开 API 变化；拖出申请继续走公开 `IFloatingDetachSource`。发布内容源新增 `mosaic-0.10.2`，既有工作空间会按既有规则生成一次“更新简要”任务。
