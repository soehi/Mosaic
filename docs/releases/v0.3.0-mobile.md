# Mosaic 手机端 0.3.0

Mosaic 手机端 0.3.0 · 更新日期 2026-11-26
适用范围：0.2.x → 0.3.0 覆盖安装，或全新安装
平台：Android（`minSdk 26`、`targetSdk 36`）；桌面端与服务端不随本版本发布
包名：`app.mosaic.tasks`；`versionCode=5`

## 这一版是什么

按 `docs/mobile-refactor-plan.md` 的基线重做的手机端：**没有 App 界面**，只有桌面小组件；任务数据来自服务端备份与增量变更的只读投影；唯一写路径是单任务 `POST /v1/sync/changes`。

- 无 Activity、无页面、无设置页：进程由系统广播拉起，`Application.OnCreate` 内完成组合，直接渲染小组件。
- 三个动作：展示未归档任务、标记完成、归档；没有取消归档、创建、编辑、删除、定时通知。
- 归档写作 `archivedAtUtc` + `deleted=false`，**不写 tombstone**。
- 每次写入带 `baseServerRevision`、`clientRevision` 与新的 `idempotencyKey`；409 用服务器当前行覆盖并提示“任务已被其他设备修改”，401 清令牌并显示会话失效，网络错误显示“离线，操作未提交”。没有 outbox、没有离线排队、没有本地乐观写入。
- 投影按 `sha256(规范化服务器地址 + NUL + userId)` 隔离；owner/schema 不匹配即隔离文件并拒绝展示。

## 流体云

阶段 0 判定本轮**不可接入**：没有 OPPO 开放平台 `ClientId`/`ClientSecret`、文档受权限控制、没有 ColorOS 15+ 真机；Android 16 Live Updates 与 HarmonyOS 实况窗都不作为“流体云”的替代。适配器边界 `IFluidCloudAdapter` 保留，卡片显示“流体云不可用”，**不使用 AppWidget 冒充**。

## 升级与不迁移声明

- **不迁移** 0.2.x 的投影、令牌与 widget 状态。升级后首次启动会把 `files/projections/` 改名为 `retired-projections-v2-<时间戳>`，删除旧偏好 `mosaic_secure` 与旧 Keystore 别名；新客户端从不读取这些数据。
- 升级后需要重新配置服务器、重新授权设备，并从服务器最新备份重建投影；服务端没有备份时卡片显示“等待首次同步”，不会用旧缓存或空列表冒充同步成功。
- 旧桌面小组件实例在新包中不再有对应 provider，系统会移除它们，需要重新添加。
- 连接方式（服务器地址与登录入口）按计划后置：当前由 `IServerConfigProvider` 注入，Android 实现读取私有偏好 `mosaic.mobile.v3.config` 的 `serverUrl`（已按 HTTPS 校验）。

## 安全

- 令牌只存 Android Keystore AES/GCM 加密的私有偏好，禁止应用备份与设备迁移。
- 仅 HTTPS；仅回环地址允许 http 供本地开发；没有忽略证书错误的选项；不内嵌 WebView。
- 布局与卡片模型不含邮箱、令牌或备注。

## 已知限制

- 流体云形态不可用（见上）。
- 本轮没有 Android 真机：小组件添加/点击回传、深色与字体放大、覆盖安装与卸载重装均**未验证**。
- 「任务提示」只做常驻展示，不做定时提醒。

## 回滚

- 代码：`git revert <本次提交>`，或回到 `backup/mobile-pre-refactor-20261126`（`8bc0acdee39fcb643e0461165ee0ba230c7e52a6`）。
- 设备：`versionCode` 从 5 回退到 4 不允许直接覆盖安装，需要卸载 0.3.0 后再安装 0.2.x；卸载会删除应用数据，旧投影与令牌不会自动恢复。
