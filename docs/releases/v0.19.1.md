# Mosaic 0.19.1

Mosaic 0.19.1 · 更新日期 2026-11-24
适用范围：首次使用 → 0.19.1

功能改进
1. 任务速览改为只读取一页且不携带备注，总数与未完成数改由一次聚合计数得到；任务与备注较多时打开更快、占用更少。
2. 主列表刷新按任务复用行对象，只更新变化的行：保存或切换筛选不再重建整张列表，选择与滚动位置保持稳定。
3. 保留 0.19.0 的账号备份附件同步：同步任务附件开关、附件清单与上传下载删除端点、恢复时逐件校验与导入均不受本次合并影响。

问题修复与兼容变化
1. 恢复整份备份后只发送一次批量变更通知，任务很多时不再逐条重载列表与浮窗。
