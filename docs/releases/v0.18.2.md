# Mosaic 0.18.2

Mosaic 0.18.2 · 更新日期 2026-11-22
适用范围：首次使用 → 0.18.2

功能改进
1. 附件文件系统访问下沉到 ITaskAttachmentBlobStore 端口：路径解析、附件根目录边界校验与文件读写删除全部封装在单一实现内，上层只按任务/附件/文件名取用，升级前写入的历史路径（stored_path）仍可读取。
2. 附件流式打开：新增 OpenReadAsync，拖出导出改为流式复制，不再依赖上层拼绝对路径，也为后续同步与手机端复用留出通道。

问题修复与兼容变化
1. 修复附件导出目标目录校验用原始字符串前缀比较、可能被同名前缀目录（如 C:\AttachmentBackup 与 C:\Attachment）绕过的问题：改用规范化后的相对路径判定。
2. 修复删除任务时若附件文件已被外部删除会中断后续附件清理的问题：文件删除改为幂等，缺失视为已删除。
3. 修复把已在附件目录内的文件再次拖入时会被当作源重新复制、并在目标同名失败时可能删掉已有附件的问题：源位于附件根目录即拒绝并给出提示，目标已存在报「已有同名文件」且绝不动原文件。
4. 修复附件列表加载失败时界面毫无反馈的问题：列表查询失败现在显示已本地化的错误提示。
5. 修复批量添加附件时取消后仍逐个继续调用接口、失败提示不显示失败数量的问题：取消立即停止，失败时显示本次失败项数。
