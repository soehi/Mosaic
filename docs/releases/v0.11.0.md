# Mosaic 0.11.0

Mosaic 0.11.0 · 更新日期 2026-11-18
适用范围：首次使用 → 0.11.0

功能新增
1. 拖出任务时显示小窗放置预览，虚线幽灵窗与最终创建位置共用坐标与夹取规则。
2. 小窗标题栏的状态、展开与工具按钮支持按住拖动窗口；阈值内短按仍执行原操作。

功能改进
1. 关闭后再拖出已打开过的任务时按本次落点放置，不再回到上次位置；尺寸、模式与置顶设置保留。

## 根因与改动

- 根因：`src/Modules/Tasks/Mosaic.Tasks.Wpf/Internal/TaskPeekView.xaml.cs`（0.10.2 基线 `FinishDrag`）只在松手后提交落点，拖动过程中没有预览输出；`FloatingSurface` 没有独立于窗口的放置预览；`FloatingWindowCoordinator.OpenCoreAsync` 存在历史记录时整条复用旧记录，落点被忽略；`FloatingWindowInput.HitTest` 对按钮返回 `HTCLIENT` 以保留点击，但没有 WPF 层阈值拖动兜底，按住按钮拖动无效。
- 改动：`FloatingContracts.cs` 与 `src/Mosaic.Presentation.Contracts/FloatingPresentation.cs` 增加预览申请；`TaskDetachSource` 转发；`FloatingWindowCoordinator` 让落点覆盖旧位置并转发预览；`FloatingSurface` 新增不抢焦点、不接收鼠标的虚线幽灵窗，`FloatingScreen` 新增与创建路径共用的 `Placement` 夹取数学；`TaskPeekView` 在拖动开始/移动/结束时提交或结束预览；`TaskPeekViewFactory` 接线；`FloatingWindowInput` 增加标题栏按钮阈值拖动，超过阈值后 `ReleaseCapture` 并以 `WM_NCLBUTTONDOWN`/`HTCAPTION` 复用系统标题栏移动循环，随后抑制点击；首版 `Window.DragMove()` 在子按钮持有捕获时移动循环会立即结束（跟踪中 `WM_SYSCOMMAND` 后 1 ms 收到 `WM_LBUTTONUP`），真实指针下窗口不动。测试覆盖落点覆盖、预览转发、幽灵窗渲染、标题栏候选范围、真实指针按钮拖动与短按、面板关闭/取消清理。
- 兼容：无数据库结构、窗口记录字段、配置文件或模块装配变化；预览不写入任何存储。发布内容源新增 `mosaic-0.11.0`，既有工作空间会按既有规则生成一次“更新简要”任务。
