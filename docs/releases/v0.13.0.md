# Mosaic 0.13.0

## 新增

- 任务支持手动归档、恢复和已确认永久删除，主列表新增“已归档”筛选。
- 设置新增自动归档开关与等待天数，已完成任务到期后自动归档。
- 设置新增“登录后启动 Mosaic”，Windows 登录时使用当前工作区自动启动。

## 改进

- 已归档任务默认从主页、速览和浮窗隐藏；恢复后继续编辑未保存草稿。
- 已归档任务在详情中只读，编辑和完成切换需先恢复。

## 修复

- 普通编辑不再影响自动归档计时基线；取消完成会停止计时。

## 兼容与迁移

- SQLite 升级新增 `003_TaskArchiving` 迁移：为 `tasks` 表补充完成、归档和恢复时间，旧已完成任务以最后修改时间回填，旧未完成时间为空，全部任务初始未归档。
- 自动归档默认关闭；等待天数默认 7 天，可设置 1–365 天。
- 开机自启默认关闭；启用后以当前保存设置时的工作区路径注册当前用户启动项，卸载时仅清理本工作区写入的项，不覆盖 Windows 任务管理器的系统级禁用状态。
- 既有任务创建凭据、Revision 乐观并发和浮窗记录保持不变。
