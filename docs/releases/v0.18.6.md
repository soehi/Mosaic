# Mosaic 0.18.6

Mosaic 0.18.6 · 更新日期 2026-11-23
适用范围：首次使用 → 0.18.6

功能改进
1. 任务列表附件提示改为矢量回形针：不依赖 Segoe MDL2 字体，胶囊底色与强调色描边在浅色与深色主题下都清晰；辅助技术读到的名称改为「含附件」，不再覆盖整行描述。
2. 深色模式补全：提示框、复选框、单选按钮、密码框、进度条、右键菜单与分隔线全部改用主题模板，窗口标题栏随主题切换深浅（DWM immersive dark mode），并提高画布、卡片与边框的层次对比。

问题修复与兼容变化
1. 启动页固定为任务页：未完成首次账户选择不再把启动路径劫持到账户设置页；未登录时账户设置页始终显示登录、设备码与离线入口，登录后自动切回账户设置。
2. 安装程序在全新安装、升级与实际修复完成后自动启动 Mosaic（静默安装、卸载与健康维护不启动），安装与升级对话框文案同步说明。
3. 更新保留用户设置：升级只替换 %LOCALAPPDATA%\Programs\Mosaic 下的程序文件，用户数据、配置、日志与备份仍从 %LOCALAPPDATA%\Mosaic 读取，登录状态、主题、语言、窗口布局与任务偏好不重置。
