# Mosaic 手机端 0.2.1

Mosaic 手机端 0.2.1 · 更新日期 2026-11-26
适用范围：0.2.0 → 0.2.1 覆盖升级（versionCode 3 → 4）
平台：Android；桌面端不随本版本发布；不新增 iOS Widget

本版本为 Android 添加桌面小组件：无需打开应用即可查看当前账号未归档、未完成的任务，并在小组件上执行标记完成、归档与取消归档；写入复用 0.2.0 的共享会话、投影和 API 客户端，没有 outbox、离线排队或独立令牌存储。

功能改进
1. 新增桌面小组件，按当前 `(normalizedServerOrigin, userId)` 投影读取未归档、未完成任务数量与标题；不读取桌面 `mosaic.sqlite`，不引用桌面 Shell/Tasks 内部程序集。
2. 提供小/大两种布局：小尺寸显示 1 行任务，大尺寸显示最多 5 行并在超出时显示“还有 N 项”；提供 content description、刷新按钮与中英文文案。
3. 每行提供标记完成、归档、取消归档三个动作；三个动作均通过 `POST /v1/sync/changes` 提交完整 camelCase `TaskItemDto`。
4. 同步 `Completed`/`StatusChanged`、投影变化、认证状态变化、写成功和显式刷新都会更新小组件；广播可能在 MainActivity 未启动时投递，小组件路径从 Android Application 的共享 DI 容器和会话恢复出发，不依赖 UI 页面。
5. `updatePeriodMillis=0`，小组件不按系统周期轮询；刷新只由显式动作、同步/认证事件与写后触发。

安全修复
1. 小组件的 provider 与 action receiver 均 `android:exported="false"`；PendingIntent 只携带 `taskId`、`taskAction`、`widgetId`，不携带令牌、邮箱、密码或完整任务 payload。
2. 写入前重新建立会话并以`服务端最新已上传备份 + 该备份 cursor 之后仍保留的增量变更`确定的投影身份为准；换号、退出或撤销设备后旧 PendingIntent 指向的任务不存在于当前账号投影，动作被拒绝并提示“任务已不属于当前账号”，不会写入本地假状态。
3. 409 冲突按 `details.current` 提示“已被其他设备修改，请同步后重试”，不做本地假写；401 提示会话失效并只读化；离线、超时、协议错误分别给出明确文案；`replayed=true` 按成功处理但不重复修改本地 revision。
4. 服务端仍只做 opaque payload swap，不校验完成/归档字段一致性，无单任务 GET，不阻止并发覆盖；本版本没有新增强语义服务端契约。
5. 每次动作使用新 `idempotencyKey`，`baseServerRevision = SyncedTask.ServerRevision`、`clientRevision = Revision + 1`，归档写 `deleted=false`，不把归档伪装成删除。

迁移与已有安装影响
- 0.2.0 → 0.2.1 可直接覆盖安装：`versionCode` 3 → 4，`versionName` 0.2.0 → 0.2.1。小组件是新增组件，旧安装不会自动添加小组件，需要用户自行在桌面添加。
- 投影 schema、账号隔离、令牌存储与同步 wire 均未改变；0.2.0 的 `mosaic-mobile.db` 投影无需迁移，已登录会话在覆盖安装后保持。
- 0.2.0 的快照引导边界继续成立：新投影从服务端最新已上传备份重建基线，再从该备份 cursor 继续拉取仍保留的增量变更；不保证覆盖从未上传快照的任务；本地未上传的旧 outbox 按设计废弃。本版本没有重新引入 outbox。
- 完成/归档写入只作用于当前账号投影里的任务；成功提交后由既有同步流程刷新其他界面。没有离线编辑：离线时动作不会排队，提示“离线，操作未提交”。
- 回滚到 0.2.0（`versionCode` 3）在 Android 覆盖安装语义下可能被系统拒绝；如需回退，需要卸载 0.2.1 后安装旧 APK，应用数据目录会随卸载删除，需重新登录并按上述边界重建投影。
