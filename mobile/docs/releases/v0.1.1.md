# Mosaic Mobile 0.1.1

更新日期：2026-11-19
适用范围：0.1.0 → 0.1.1（手机端首个发布候选）

## 变更

1. 与 Mosaic Server 0.1.1 最终 wire 对齐：
   - 同步写入改为单条 `POST /v1/sync/changes`，支持 `deleted`、`baseServerRevision`、`clientRevision`、`idempotencyKey`，解析 `{change,replayed}` 与 `409 sync.conflict` 的 `details.current`。
   - 游标失效同时处理 `410 sync.cursor_invalid` 与 `400 sync.invalid` + `details.requiresSnapshot=true`；普通 `400 sync.invalid` 不再清空本地投影。
   - 会话响应接受 `expiresIn` 与 `account{userId,email,displayName}` 超集，`/v1/auth/me` 同时接受嵌套 `user` 与根级账户字段。
   - Device Flow 优先打开服务端 `verificationUriComplete`；`slow_down` 按 200 响应返回的 `interval` 递增；`device/info` 解析 `appVersion` 与 `approvedAt`。
   - 错误码切换为服务端规范集（18 个），继续兼容 `auth.code_invalid`、`auth.password_policy`、`sync.idempotency_mismatch` 旧别名。
   - 会话管理支持 `revoke-all` 的 `{keepCurrent:true}`。
2. 版本号提升为 `0.1.1`（`ApplicationVersion`/`CFBundleVersion` = 2）。
3. 新增 Android 打包脚本骨架 `mobile/build/package-android.ps1`。

## 构建

- 工程：`mobile/src/Mosaic.Mobile.App/Mosaic.Mobile.App.csproj`。
- 依赖：.NET 10 SDK、MAUI workload、Android SDK；iOS 需要 macOS + Xcode。
- Android：

```powershell
powershell -ExecutionPolicy Bypass -File mobile\build\package-android.ps1 -Format aab
```

- 签名通过环境变量提供：`MOSAIC_ANDROID_KEYSTORE`、`MOSAIC_ANDROID_KEYALIAS`、`MOSAIC_ANDROID_KEYPASS`、`MOSAIC_ANDROID_STOREPASS`；未提供时产物未签名，仅用于本地验证。
- 产物位于 `bin/Release/net10.0-android/<rid>/publish/`，按 `*.aab` 或 `*.apk` 查找。

## 已知限制

- 手机端仍为只读同步；离线编辑、outbox 排空与冲突选择 UI 属于第二阶段。
- 包名固定为 `app.mosaic.tasks`，上架后不可更改。
- 商店渠道、隐私政策与账号删除审核材料尚未准备。
