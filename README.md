# Mosaic

0.16.0（2026-11-19）：左侧导航新增“账户”页，登录完全可选——可以连接其他自建服务器、用浏览器授权码登录或在登录页完成邮箱注册与找回密码，不连接服务器也能使用全部本地功能，启动不联网、不强制登录。登录后可把任务与可移植用户设置备份到自建服务器并在其他设备上恢复，第一阶段为显式上传/下载，下载覆盖本机任务前必须确认；刷新令牌只用 Windows DPAPI 加密保存在本机，所有网络请求强制 HTTPS。

0.15.3（2026-11-19）：强化自动归档开关的回归测试，关闭时断言归档循环根本没有启动、超过等待期的已完成任务保持未归档，开启后只归档候选任务并在关闭后停止；产品行为与 0.15.2 一致。

0.15.2（2026-11-19）：补上自动归档开关的启停回归测试，确认关闭时超过等待期的已完成任务也不会被归档、开启后只归档等待期已满的已完成任务并在关闭后立即停止；产品行为与 0.15.1 一致。

0.15.1（2026-11-19）：已归档任务页在构造期即锁定“已归档”筛选，页面上不再显示“新建任务”按钮和筛选下拉；修复设置中的默认筛选晚到或再次应用时把归档页筛选覆盖回“全部/未完成/已完成”的问题。

0.15.0（2026-11-19）：左侧导航新增“已归档任务”入口，使用独立页面查看已归档任务并可把任务恢复到任务区；归档页有独立标题、空态与计数，恢复后停留在当前页。设置中的自动归档说明明确未完成任务永远不会被自动归档。

0.14.0（2026-11-19）：任务速览浮窗在进入备注编辑前，正文空白、底部按钮周边与标题下方空白都可以直接拖动窗口，文字选择、按钮、滚动条与编辑态保持原交互；设置新增“任务速览入口显示时机”，可选择关闭主窗口后出现（默认）、最小化后出现或一直显示。

0.13.1（2026-11-18）：任务速览详情改为卡片式只读视图，备注可选中复制且点击后不再出现绿色焦点框；修复 0.13.0 安装包缺少正式发布标记而未能生成“更新简要”的问题，升级后会补发生成一条覆盖 0.13.0 与 0.13.1 的更新简要。

0.13.0（2026-11-18）：任务支持手动归档、恢复和已确认永久删除，主列表新增“已归档”筛选；设置新增自动归档开关与等待天数；设置新增“登录后启动 Mosaic”，Windows 登录时使用当前工作区自动启动。已归档任务默认从主页、速览和浮窗隐藏，恢复后可继续编辑未保存草稿。

0.12.2（2026-11-18）：应用内按钮松开后结束按压反馈，键盘焦点通过独立标记提示；浮窗置顶仅用图钉形状区分状态，指针移开后清除按钮底色。

0.11.0（2026-11-18）：拖出任务时新增小窗放置预览，虚线幽灵窗与最终创建位置共用坐标与夹取规则；小窗标题栏的状态、展开与工具按钮支持按住拖动窗口，阈值内短按仍执行原操作。关闭后再拖出已打开过的任务按本次落点放置，尺寸、模式与置顶设置保留；任务数据仍只通过 Tasks API 提交。

当前版本为 0.16.0。左侧导航提供“账户”页面：不连接服务器即可离线使用全部本地功能；连接自建服务器后可用浏览器授权码登录、邮箱注册、找回密码，并把任务与可移植设置（外观主题、语言、任务规则与界面文案）备份到服务器或从服务器恢复。恢复会整体替换本机任务，操作前需确认；服务器地址、模块装配、机器路径、驻留/自启设置、令牌与日志都不会进入备份。左侧导航仍提供独立的“已归档任务”页面。实际验证范围见[实施记录](docs/implementation-status.md)。

Windows 安装包：[下载 Mosaic 0.16.0](https://github.com/soehi/Mosaic/releases/download/v0.16.0/Mosaic-0.16.0-win-x64.msi)。发布文件自带 .NET 10.0.15 运行时，无需安装 SDK。

目标为 Windows 10 2004（build 19041）及以上的 x64 系统；已验证 Windows 11 x64。其他系统、ARM64、干净虚拟机及不同 DPI/输入法组合仍需独立验收。

开发需要 .NET SDK 10.0.300（global.json 锁定），构建与验证：

```powershell
dotnet restore Mosaic.sln --locked-mode -m:1
dotnet build Mosaic.sln -c Release --no-restore -m:1
pwsh -File build/publish.ps1
pwsh -File build/test.ps1 -NoBuild
dotnet format Mosaic.sln --verify-no-changes --no-restore
dotnet run --project src/Mosaic.Desktop
```

`build/test.ps1` 使用 xUnit 可执行测试入口；桌面测试需要可交互的 Windows 桌面，并在 `artifacts/smoke-data` 中隔离数据。无桌面时使用 `-SkipDesktop`。也支持 .NET 10 的 `dotnet test --solution Mosaic.sln -c Release --no-build --no-restore`；受限宿主可能不允许其命名管道。

若官方 NuGet v3 签名元数据端点连接失败，可用 `pwsh -File build/publish.ps1 -UseV2Feed` 切换到官方 v2 源；仍保留锁文件与包签名验证。

构建安装包（WiX SDK 4.0.6 自动还原；PowerShell 7）：

```powershell
pwsh -File build/package.ps1 -NoPublish
```

本机仅使用一个完整发布目录 `artifacts/local-run`，安装包输出到 `artifacts/installer`；bin/obj 为开发构建缓存。

安装包当前默认安装到 `%LOCALAPPDATA%\Programs\Mosaic`，0.9.1 起安装完成后自动创建桌面和开始菜单快捷方式；自定义安装位置、旧安装替换提示与跨位置卸载规则仍待实施。数据、配置、日志分别位于 `%LOCALAPPDATA%\Mosaic\Data`、`Config`、`Logs`。首次复制默认配置，后续无效配置保留原文件并显示诊断；模块配置修改后重启生效。`modules: []` 不打开数据库。卸载保留用户数据。

可使用 `Mosaic.Desktop.exe --data-root D:\Some\Absolute\Folder` 运行独立工作空间；参数路径必须为绝对路径。数据库备份为同目录中的 `mosaic.sqlite.backup-*.sqlite`，升级前自动生成；恢复时先完全退出程序，再保留当前数据库副本并用所选备份替换。

核心约束：每项职责只有一个归属模块；跨模块只允许通过公开协议提出调用申请，禁止访问内部实现和数据；缺少能力时先判断职责归属，再扩展公开接口或创建模块；宿主负责装配；导航和页面入口由已激活功能的贡献参数生成。

后台驻留与模块边界见 [驻留规划](docs/desktop-presence-plan.md)。新工作空间默认关闭主窗口后进入驻留；通过边缘入口可恢复或退出。0.9.1 不改变配置、数据库或窗口记录结构，已有安装直接升级。
